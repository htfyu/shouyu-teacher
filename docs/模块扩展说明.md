# 模块扩展说明

## 1. 当前模块

已交付并可用：

- 智能备课（教案）
- 学生材料（任务单 / 工作页）
- 教学评价（评价表）
- 实训安全查询（电工 / PLC 操作级）
- 听课评课
- 资料中心、知识库管理、历史、编辑器、导出、AI 设置

## 2. 未实现为独立模块

以下只在需求中提出，当前没有用空页面冒充：

- 智能命题（选择 / 判断 / 填空 / 简答 / 实操 / 组卷 / 难度）
- PPT 大纲与课件制作
- 教学资源案例 / 任务书 / 指导书独立表单
- 教研活动总结 / 教学工作总结
- 课程 / 班级 / 进度 / 任务 / 成果归档管理

它们可作为下一阶段独立模块实现。目前可在 AI 对话中用自然语言讨论，但没有结构化表单、独立导出与数据模型。

## 3. 新增一个教学模块的步骤

1. 在 `js/knowledge.js` 的 `SCENES` 增加场景描述、必填字段与输出说明；
2. 在 `js/app.js` 的 `buildFormFields()` 增加表单字段；
3. 在 `js/engine.js` 增加本地生成函数，返回统一结构：

```js
{
  docs: [{ id, label, title, meta, sections: [{ id, no, title, blocks, refs }] }],
  meta: {},
  warnings: [],
  sourcesOverride: [] // 可选
}
```

4. 在 `generate()` 中路由到新函数；
5. 如需 AI 增强，在 `js/ai-prompts.js` 增加场景提示词，并在 `js/ai-artifacts.js` 的默认结构映射中确认可合并；
6. 添加 `tests/engine.test.mjs` 用例与浏览器回归；
7. 加入导出与历史（现有通用能力自动覆盖）。

## 4. 模块隔离原则

- 业务模板与知识库数据分离；
- 生成函数只返回结构化数据，不直接操作 DOM；
- UI 统一由块渲染器输出；
- 新模块必须复用引用、隐私、合规、编辑器、导出能力，不复制一套；
- 没有真实数据处理能力的按钮不放到界面。

## 5. 后续优先级建议

1. 智能命题（与现有评价 / 知识库复用度高，导出 XLSX 即可用）；
2. 教学反思 / 教研总结（文本型，AI 改写收益高）；
3. 课程 / 班级 / 进度管理（需要 IndexedDB 数据模型与权限设计）；
4. PPT 大纲（先输出 DOCX / Markdown，再考虑 PPTX 渲染）；
5. 账号 / 云端同步 / 学校级知识库（需要后端与认证，不能只改前端）。
