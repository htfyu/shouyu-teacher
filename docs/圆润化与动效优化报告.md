# 授渔 UI 圆润化与动效优化报告

> 日期：2026-11-18  
> 范围：视觉与交互体验优化，不修改导航结构、业务逻辑、数据结构、AI 生成/编辑/保存/导出流程。  
> 样式加载顺序：`styles.css → ui-refresh.css → work-theme.css → rounded-motion.css`

## 一、本次改动

### 新增统一视觉层

新增 `assets/rounded-motion.css`，作为最后一层视觉覆盖，不改动原有工作型主题和业务代码。

### 圆角语言

| 层级 | 变量 | 值 |
|---|---|---:|
| 小型控件 | `--ui-radius-xs` | 8px |
| 按钮 / 输入框 | `--ui-radius-control` | 10px |
| 卡片 | `--ui-radius-card` | 14px |
| 面板 | `--ui-radius-panel` | 16px |
| 弹窗 | `--ui-radius-modal` | 20px |
| 胶囊 / 标签 | `--ui-radius-pill` | 999px |

覆盖范围：

- 按钮、图标按钮、关闭按钮；
- 输入框、下拉框、文本域；
- 搜索框容器；
- 课程行、课程卡片、项目卡片、场景卡、资料行、成果卡、质量报告卡；
- 侧栏导航、更多功能、最近项目；
- 弹窗、弹窗头尾、遮罩；
- 标签、徽标、计数；
- 表格外层容器。

### 动效参数

| 类型 | 时长 | 缓动 |
|---|---:|---|
| 按钮 / 导航反馈 | 150ms | `cubic-bezier(0.22, 1, 0.36, 1)` |
| 输入框 / 链接 | 150–200ms | 同上 |
| 卡片悬停 | 200ms | 同上 |
| 下拉菜单 | 190ms | 同上 |
| 弹窗进入 | 240ms | 同上 |
| 弹窗退出 | 160ms | 同上 |
| 页面切换 | 270ms | 同上 |
| Toast | 190ms | 同上 |

### 具体反馈

- 按钮悬停：背景、边框、阴影平滑变化；
- 按钮按下：`scale(0.985)` 轻微回弹；
- 禁用：降低透明度并降低饱和，不改变布局；
- 输入框聚焦：品牌色边框 + 柔和外环；
- 卡片悬停：上浮 2px、阴影增强、边框变柔；
- 课程行悬停：内描边，不发生布局位移；
- 页面切换：透明度 + 7px 位移，只在新路由时触发；
- 弹窗：遮罩淡入、弹窗缩放淡入；关闭时先播放退出动画，再清理 DOM；
- 下拉菜单：轻微淡入 + 垂直位移；
- Toast：轻量上浮淡入；
- 运行状态：状态点轻微呼吸，不抢眼。

### 减少动态效果

`prefers-reduced-motion: reduce` 下：

- 页面、弹窗、下拉、Toast 动画接近即时；
- 卡片和按钮不位移；
- 平滑滚动手动关闭；
- 功能、焦点和点击不受影响。

## 二、功能保护

未修改：

- 导航结构；
- 路由；
- 数据结构；
- IndexedDB / localStorage 读写；
- AI 生成与编辑流程；
- 保存、质检、审核、导出；
- 文件解析；
- 业务判断。

JS 仅新增两处配合：

1. `renderView()` 在路由变化时给 `.view` 加 `is-route-enter`，用于页面进入动画；同一路由内的输入/搜索重渲染不会重复播动画。
2. `closeModal()` 在支持动效时先给遮罩加 `is-closing`，180ms 后清理 DOM；`prefers-reduced-motion` 下立即清理；新弹窗打开会取消旧的关闭计时器。

## 四、已知限制

- 原生 `<select>` 的下拉面板由浏览器绘制，无法统一圆角；
- 移动端不是本次主验收目标，只保证无溢出和可操作；
- 没有引入动效库，复杂弹簧/物理动效不做；
- 弹窗关闭采用固定 180ms 退出窗口，若未来需要更强动画可改为 `animationend`；
- 现有基础层仍有历史死 CSS，本次未做物理删除。

## 五、结论

本次优化把“尖锐、生硬”的边角统一为 8/10/14/16/20/999 的圆角层级，并把按钮、输入、卡片、弹窗、下拉、页面切换的反馈统一到同一组 150–270ms 动效参数。所有业务功能保留，无数据结构变更。
