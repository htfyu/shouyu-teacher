# 授渔 V2 · 竞赛级升级审计报告

> 审计时间：2026-11-17  
> 审计对象：当前 `main` 分支（commit `0461a43`）及线上站点  
> 审计原则：区分“真实实现”“部分实现”“纯展示”；不以 README 代替代码检查。

## 一、现有架构事实

- 纯静态 ES Module 前端，无构建步骤；GitHub Pages 部署；`index.html` + `js/*.js` + `assets/*.css` + `data/*`。
- 运行时状态集中在 `js/app.js` 的 `state`，对话/知识/文件/设置为 IndexedDB `jiangbei_v2`，专业库修订为 `shouyu_programs_v1`，localStorage 兼容回退。
- 本地规则引擎 `js/engine.js`：检索、五场景结构化生成、合规边界；不是大模型。
- AI 适配 `js/ai.js`：公开体验通道 `text.pollinations.ai` 或 `server/` 安全代理；流式 SSE；无前端 Key。
- 专业知识库：33 份材料 / 147 个章节（`knowledge.js` + `knowledge-packs.js`）。
- 专业数据库：6 系 / 13 组 / 56 专业条目 / 75 招生计划 / 567 课程记录 / 134 来源（`programs-*.js`）。
- 测试：升级前 72 项单元测试、45 项浏览器 E2E；第一次升级 82/56；2026-11-17 竞赛冲刺二次优化后 94 项单元测试、67 项 E2E（实际执行结果）。

## 三、已确认可复用能力

- `programs-data.js`：完整专业层级、课程记录、来源；可直接作为教学引擎的课程目录。
- `programs-content.js`：课程资源 10 模块、官方/参考/待完善分层；可作为非代表性课程的参考骨架。
- `knowledge.js` / `knowledge-packs.js`：已有 PLC、电气、机器人等校本示例章节；可作为知识包来源。
- `engine.js` 的 `retrieve()`、`sourceForRef()`：可复用检索与来源解析。
- `export.js` 的 DOCX/XLSX/Markdown/打印：可复用导出。
- `privacy.js`：AI/文件发送前隐私检测，可复用。
- `db.js`：IndexedDB 与备份，可复用。
- `ui-refresh.css`：设计 Token 和 SaaS 组件，可继续扩展。

## 四、审计结论

现有项目的“展示层”和“资料处理层”成熟，但“专业知识驱动的教学引擎”和“质量评价闭环”尚未真正建立。竞赛升级的核心不是再加一个聊天框，而是：

1. 选一门有真实来源的代表性课程；
2. 建立结构化课程知识包；
3. 用课程知识装配 10 类教学资源；
4. 用规则化质检证明资源质量；
5. 用版本/审核/导出闭环保存成果；
6. 用可重复演示案例证明系统真实可用。

本报告形成后直接进入 P0 实施，不因审计停止开发。
