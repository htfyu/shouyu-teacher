- 每个一级菜单独立线性图标颜色；
- 当前项 = 对应浅底 + 左侧 3px 色条 + 深色文字；
- 分组留白、悬停柔和、计数深灰；

- 品牌标识保持原黑白莫比乌斯鱼钩。

### 5. 微文案

减少 AI 宣传式表达：

- “AI 增强” → “增强模式”；
- “AI 正在思考” → “正在整理课程资料……”；
- “AI 教研建议” → “教研建议”；
- “AI 辅助草稿” → “增强草稿”；
- “不是让 AI 写一篇教案” → “不是让工具代写一篇教案”。

保留必要技术边界：

- AI/增强模式的数据传输说明；
- “规则评分不是学校官方认定”；
- “知识包待教研组审核”；
- “没有真实数据时显示尚未采集”。

## 二、改造中发现并修复的问题

1. **页头主按钮文字不可见**：`.page-head-actions .btn` 的优先级覆盖了 `.btn-solid` 背景，导致白字白底；改为只给 `.btn-ghost` 加纸面背景。
2. **智能备课质检条被色块盖住**：误把标签 `span` 当进度条；改为只给 `.studio-quality-track i` 上色。
3. **编辑器标签仍是暖金色**：`chat` 路由错误继承工作台色；拆分为陶土橘，并让侧栏“智能备课中心”在对话/编辑器中保持当前态。
4. **结果区质检面板过窄**：把结果区改为单列，质检条恢复两列，教师专家层独占整行，避免“未提交教师专业审核”挤成窄条。
5. **统计卡重复模板感**：专业体系改为索引带；备课、质检、成果改为细线统计带；工作台保留卡片但用不同底色区分。
6. **空按钮/空白框**：页头导入、新增、管理按钮均重新检查，扫描所有一级页面无“文字颜色 = 背景色”的不可见按钮。

## 七、已知限制

1. **衬线字体依赖本机字体**：未加载外部字体文件，Windows 上可能回退到宋体/SimSun；不影响可读性，但不同系统字形略有差异。
2. **视觉验收为截图 + 计算样式检查**，没有接入像素级截图 diff 服务；后续样式改动仍建议人工复看。
3. **未做真机触屏测试**：390 / 768 为 Edge headless 视口，触摸手势仅由现有 E2E 与移动端结构间接验证。
4. **原有技术说明仍保留 AI 字样**：设置、授权、架构说明必须如实描述数据边界，不属于营销文案；首页、备课、质量、演示的可见区域已收敛。
5. **模块颜色只做强调**：没有把整页铺成高饱和色块，避免影响长文本阅读和打印。

**结论：** 视觉改造完成，八大模块可一眼区分，页面不再是统一蓝色 SaaS 模板；原有业务功能、路由、存储、质检与演示流程保持可用，回归测试全部通过。
