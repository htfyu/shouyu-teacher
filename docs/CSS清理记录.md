## 三、基础层中的死样式

已确认新页面不再生成、但仍在基础层保留的选择器：

- `.workbench-hero*`
- `.workbench-grid*`
- `.workbench-card*`
- `.workbench-recent*`
- `.kb-card*`
- `.kb-grid`
- `.quality-rule-panel`
- `.quality-report-list`
- `.studio-layout`

这些规则不会命中新页面 DOM。未直接删除的原因：

1. 项目无构建步骤，基础层与响应式媒体查询交织；
2. 部分选择器与 `styles.css` 的旧组件块共用；
3. 需要逐块视觉回归，避免误删编辑器和文件中心仍在使用的边框/布局。

后续清理顺序：

1. 用 DOM 使用清单确认选择器为 0；
2. 在独立分支逐块删除并跑 94 单元 + 73 E2E；
3. 删除后再做五个视口截图对照。

## 四、覆盖链现状

```text
styles.css        基础结构 / 编辑器 / 文件 / 表单
ui-refresh.css    第一版组件层（Token 被覆盖）
work-theme.css    工作型 Token / 布局 / 组件收敛
```

- 新页面只依赖 `work-theme.css` 的布局类；
- 基础层不再定义页面背景和模块主题；
- `--accent` 已统一指向品牌色 `#4A5F52`；
- 模块色只存在于 `html[data-route]` 的 `--module`，不再覆盖 `--accent`；
- 不再新增“某页面专属”的颜色覆盖，除必要的模块识别标记。

## 五、清理效果

- 主题文件从 2 层（`ui-refresh` + `brand-theme`）收敛为 1 层（`work-theme`）；
- 整页模块底色、纸纹、渐变 Hero、环形装饰、非对称大圆角不再存在；
- 主按钮从 8 种模块色收敛为 1 种品牌操作色；
- 核心页面不再渲染旧卡片/统计结构；
- 新增页面样式集中在约 733 行的 `work-theme.css`，便于后续维护。
