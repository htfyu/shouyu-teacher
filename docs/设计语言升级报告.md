# 授渔设计语言升级报告

> 日期：2026-11-18  
> 方向：Craft 的温润阅读感 × Linear 的清晰秩序 × Raycast 的轻巧操作 × Framer 的自然反馈  
> 边界：视觉、排版、间距、组件状态、响应式；不修改导航结构、路由、数据结构、AI、保存、质检和导出流程。

---

## 1. 设计语言

这次不是把四个产品拼在一起，而是提炼成一套授渔自己的规则：

- **Craft**：用米白画布、白纸内容区和低对比边框建立温和的阅读层次；
- **Linear**：全站统一页面框架、标题区、工具栏和内容宽度；同一类信息只出现一个视觉焦点；
- **Raycast**：搜索、工具栏和辅助面板保持紧凑，但不拥挤；选中态清楚；
- **Framer**：动效只解释状态变化，不表演；结束后不残留合成层。

新增样式层：

```text
styles.css
→ ui-refresh.css
→ work-theme.css
→ rounded-motion.css
→ design-language.css
```

`design-language.css` 只负责页面框架、字体层级、间距、表面层次、阅读区和密度，不触碰业务代码。

## 2. 页面框架

### 统一页面宽度

| 屏幕 | 页面实际宽度 |
|---|---:|
| 1440 | 1180px |
| 1920 | 1280px |
| 页面最大宽度 | 1240px（≥1600px 屏 1280px） |
| 内边距 | `clamp(24px, 3.2vw, 46px)` |

实际测量 1440px 下：

```text
所有主页面：x=260，width=1180
所有页面头部：x=306
```

包括：

- 工作台；
- 我的课程；
- 课程工作空间；
- 备课工作室；
- 我的成果；
- 质量检测；
- 知识库；
- 专业数据库；

- 知识图谱；
- 模板库；
- 历史记录；

- 教学应用成效；
- 演示页。

不再出现“首页 1360、课程 1440、备课 1600”的宽度漂移。

### 标题区

- 主标题 27—31px；
- 页面副标题 13px / 1.7；
- 页面头部统一 18px 底部内边距、28px 间距；
- 标题区只保留一个主操作，按钮不与标题争夺焦点。

## 3. 字体与阅读

### 字号层级

| 层级 | 字号 |
|---|---:|
| 页面主标题 | 27—31px |
| 工作区标题 | 20—22px |
| 列表标题 | 14px / 600 |
| 正文 | 14px / 1.65 |
| 辅助文字 | 12px |
| 微型标签 | 10.5—11px |
| 文档阅读正文 | 13—13.5px / 1.8 |

具体：

- 课程行标题、首页课程标题、知识库行标题提升到 14px；
- 课程元信息、课程计数、知识条目说明提升到 12px；
- 专业数据库卡片说明提升到 12px；
- 右侧质量面板的小字从 8—9px 提升到 10—11.5px；
- 文档正文从偏小的密度提升到 13.5px，行高 1.8；
- 质量审阅文档正文 13px / 1.8；
- 表格正文 12—12.5px，行高 1.65。

### 清晰度

上一轮已修复：

- 动画结束后残留 `transform` 导致的文字发虚；
- 常驻 `will-change`；
- Windows 上强制 `antialiased` 导致中文小字发虚。

本层继续保证：

- 文档不使用过小字号；
- 辅助文字不再依赖 8—9px 的“装饰性微型字”；
- 低对比文字只用于真正的次要信息。

## 4. 搜索与工具栏

- 搜索框高度 40px，圆角 12px；
- 默认使用米白表面，聚焦时变白并出现柔和品牌色外环；
- 搜索输入 13.5px；
- 筛选器高度 40px，与搜索框对齐；
- 课程工具栏上下间距统一为 14px；
- 不新增第二套搜索或命令系统。

---

## 5. 组件统一

### 按钮

- 主按钮、次按钮、文本按钮统一 11px 圆角；
- 主按钮高度 34px，顶栏紧凑按钮保留 32px；
- 主按钮只承担当前页面最重要的动作；
- 次按钮保持安静，不与主按钮抢色。

### 卡片

- 卡片仍只用于真实分组、独立成果、可交互行或需要强调的提示；
- 静态卡片不堆叠重阴影；
- 课程行、资料行、成果卡使用低对比边框和背景层次；
- 工作台“继续上次备课”使用左侧模块色细标，不做大面积渐变。

### 文档区

- 左目录 214px，主文档自适应，右面板 320px；
- 文档正文 13.5px / 1.8；
- 章节标题 14px；
- 元信息 11px；
- 表格 12.5px，边框使用低对比线；
- 质量面板 A/B 两层并排，C 教师专家状态独占一行，避免窄栏内文字互相挤压。

### 质量页

- 审阅文档正文 13px / 1.8；
- 问题标题 12.5px；
- 问题元信息 10.5—12px；
- 问题详情、依据与建议保持可读，不靠 9px 小字承载关键信息。

## 8. 已知限制

- 原生 `<select>` 下拉面板仍由浏览器绘制，无法统一圆角；
- 移动端本次只保证无横向溢出和核心操作可用，不是主验收目标；
- 质量审阅页信息密度高，仍需要保持三栏工作方式，没有改成卡片流；
- 没有引入 UI 框架或动效库；
- 部分历史组件仍带有旧的细边框，但已统一到低对比色；
- 真实教师长时间使用测试尚未进行。

---

## 9. 结论

授渔现在有统一的页面框架、字号层级和阅读节奏：

- 主页面不再各自为政；
- 卡片不再承担所有分组；
- 文档阅读区更像生产力软件，而不是后台表单；
- 搜索、按钮、弹窗和面板使用同一套圆角、表面和反馈语言；
- 动效在状态变化时出现，结束后不残留。

最终目标不是“像 Craft/Linear/Raycast/Framer”，而是让授渔自己看起来像一个安静、清楚、可靠的教学工作空间。
