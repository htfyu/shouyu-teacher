## 2. 教材导入与识别：可用，但需区分文本型与扫描型

### 2.1 DOCX

实际测试结果：

```text
格式：docx
识别字符：662
内容块：24
页数：0（DOCX 无固定页）
needsOCR：false
警告：Unrecognised paragraph style: 'Title'
```

结论：

- DOCX 中文内容可以真实提取；
- 标题、段落、列表可以识别；
- 样式警告不影响内容；
- 可以作为第一阶段教材导入的可靠格式。

### 2.2 文本型 PDF

实际测试结果：

```text
格式：pdf
识别字符：433
页数：1
内容块：1
needsOCR：false
```

结论：

- 中文 PDF 文本可真实提取；
- 可按页返回文本；
- 适合作为“教师导入教材”的演示格式。

### 2.3 扫描型 PDF

实际测试结果：

```text
格式：pdf
可提取字符：8（仅“第 1 页”）
needsOCR：true
警告：PDF 第 1 页几乎没有可提取文本，可能是扫描件或图片页。未启用 OCR，因此未生成推测文本。
```

结论：

- 系统能识别“这是扫描件”；
- 未启用 OCR 时不会伪造文本；
- 这是正确行为；
- OCR 需要联网加载 Tesseract，尚未在本轮做准确率验证；
- 比赛演示应优先使用文本型 PDF / DOCX，避免把 OCR 作为唯一依据。

### 2.4 资料中心实际导入

在资料中心选择 DOCX 后：

```text
本机资料：1 份
综合布线-网线制作-测试样张.docx
已解析 · 1 个片段 · 662 字 · docx
```

结论：

- 不只是底层解析可用，现有资料中心 UI 也能完成真实导入；
- 有解析结果、字符数、片段数；
- 无控制台错误；
- 可作为阶段 1 教材导入的基础。

### 2.5 结论

| 能力 | 结论 |
|---|---|
| DOCX 导入 | 可用 |
| 文本型 PDF 导入 | 可用 |
| 扫描件检测 | 可用 |
| 扫描件 OCR | 未验证，依赖外部 Tesseract |
| 失败时不伪造 | 已验证 |
| 页码/片段定位 | 文本 PDF 可按页；DOCX 无固定页 |

## 3. Word / PDF 导出：Word 可用，PDF 与分册不满足目标

### 3.1 Word

从真实教学项目导出并打开：

```text
文件：export-test.docx
段落：349
表格：24
状态：python-docx 可正常打开
```

结论：

- Word 合并版可生成；
- 中文内容可写入；
- 表格可保留；
- 可作为现有基础复用。

### 3.2 PDF

当前实现：

- `studio-export-pdf` 调用 `printArtifact`；
- 通过隐藏 iframe 打开浏览器打印面板；
- 没有直接生成 `.pdf` 文件下载。

实际检查：

```text
iframe 内容长度：32942
iframe 标题：PLC技术及应用 · 物料分拣站 I/O 分配与接线检查 · 教学设计方案
下载链接：0
```

结论：

- 内容能进入打印页面；
- 但“PDF 导出”目前是“打印/另存为 PDF”；
- 不符合“点击导出直接拿到 PDF 文件”的目标；
- 阶段 1/3 需要补直接 PDF 生成或明确的打印流程设计。

### 3.3 分册版

现状：

- 只有合并版 Word；
- 没有分册版导出；
- 没有“每份材料单独下载”的 UI；
- 没有 Word/PDF 组合选择。

结论：

**分册版是必须新增的能力，不属于现有能力。**

### 3.4 导出结论

| 能力 | 现状 | 目标差距 |
|---|---|---|
| 合并版 Word | 可用 | 基本满足 |
| 合并版 PDF | 仅打印 | 需直接 PDF 或明确打印流程 |
| 分册版 Word | 未实现 | 必须新增 |
| 分册版 PDF | 未实现 | 必须新增 |
| 导出记录 | 部分 | 需与项目版本绑定 |

### 5.4 实际生成验证

从 `/course/course-0159` 开始备课：

```text
第 2 步：章节/任务已带入
章节：网线制作与工艺控制
```

已修复一个真实问题：

- 原逻辑默认取“第一章 + 第一个任务”，会出现“施工准备章节 + 网线制作任务”的错配；
- 现在任务带 `chapterId`，默认选择任务所在章节；
- 课程页任务不再在多个章节重复。

### 5.5 边界

本内容包是**校本教学示例**，不是学院正式课程标准：

- 课程身份来自专业数据库；
- 公共来源使用 S44（2026招生简章）与 S45（信息安全与智慧网络专业介绍）；
- 原课程行误引 S1/S7/S36，已记录为来源修订建议；
- 线缆类别、连接器件、测试项目和验收标准需课程负责人/教研组核对；
- 教材样张为测试样张，不是正式出版教材。

结论：

**现在可以真实支撑“网线制作”的完整备课演示，但内容仍需教研组审核，不能称为官方标准。**
