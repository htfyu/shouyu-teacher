# 代表性教学成果示例

本目录是授渔 `#/studio` / `#/demo` 使用课程知识包实际生成的成果，不是手工排版的 PPT 截图。

| 文件 | 课程 / 内容 |
|---|---|
| `01-...docx` | PLC技术及应用：标准 DOCX，含封面、目录、10 类资源、来源附录、教师/教研组签字区 |
| `02-...md` | PLC 10 类资源 Markdown 全文 |
| `03-...md` | PLC 三层质检报告（A 结构 / B 专业知识 / C 教师专家） |
| `04-...json` | PLC 结构化资源包 + 质检报告 |
| `05-...docx` | 工业机器人操作与应用：标准 DOCX |
| `06-...docx` | 新能源汽车底盘与维修：标准 DOCX |
| `07-...json` | 工业机器人资源包 + 质检报告 |
| `08-...json` | 新能源汽车资源包 + 质检报告 |

## 边界

- 4 门知识包均为**校本示例 · 待教研组审核**，不是广州市技师学院正式课程标准；0 门已正式审核；
- 三份 DOCX 的教师/教研组签字区是空白模板，不代表已通过学校审核；
- 质检报告最高 84 分（待审核知识包 + 未专家确认双重封顶）；来源覆盖率不等于事实正确率；
- 设备型号、I/O 地址、软件版本、安全权限以现场设备说明书和实训室规程为准；
- 原表课程来源编号存在 3 组错配，知识包使用比对后的来源，原值保留并警示；
- 本成果用于演示“专业知识 → 10 类资源 → 三层质检 → 审核 → 导出”的完整链路，不声称真实课堂试用成效。

## 复现

打开 <https://htfyu.github.io/shouyu-teacher/#/studio>，选择标杆课程，点击“生成 10 类教学资源”，再导出 DOCX/JSON。相同输入生成相同结构；时间戳、随机 id 和打印页码会不同。
