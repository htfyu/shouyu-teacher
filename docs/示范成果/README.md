# 代表性教学成果示例

本目录是授渔 `#/demo` 固定演示案例实际导出的成果，不是手工排版的 PPT 截图。

- 案例：机电一体化技术 / PLC技术及应用 / 物料分拣站 I/O 分配与接线检查
- 生成方式：本地规则引擎 + 课程知识包 `CUR-PLC-001`，不调用外部模型
- 质量分：84 / 100（知识包“待教研组审核”，按规则封顶 84）
- 文件：
  - `01-...docx`：标准 DOCX，含封面、文档目录、10 类资源、来源附录、教师/教研组签字区；
  - `02-...md`：10 类资源的 Markdown 全文；
  - `03-...md`：质量检测报告（10 维、问题、位置、建议）；
  - `04-...json`：资源包结构化数据（10 个文档、10 条来源、质检报告）。

## 边界

- 知识包是**校本示例 · 待教研组审核**，不是广州市技师学院正式课程标准；
- 设备型号、I/O 地址、软件版本、安全权限以现场设备说明书和实训室规程为准；
- 教师审核签字区是空白模板，不代表已通过学校审核；
- 原表课程来源编号 S20/S27 与其他专业错配，代表知识包未使用这两个编号；
- 本成果用于演示“专业知识 → 10 类资源 → 质检 → 审核 → 导出”的完整链路，不声称真实课堂试用成效。

## 复现

打开 <https://htfyu.github.io/shouyu-teacher/#/demo>，点击“运行演示案例”，再导出 DOCX/Markdown。相同输入生成相同结构；时间戳与浏览器打印页码会不同。
