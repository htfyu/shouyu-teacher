## PLC技术及应用 · 物料分拣站 I/O 分配与接线检查 · 教学设计方案

**专业：** 机电一体化技术　**课程：** PLC技术及应用　**章节：** PLC 硬件、I/O 与安全边界　**典型工作任务：** 物料分拣站 I/O 分配与接线检查　**教学对象：** 36 人（演示班级，基础待教师补充）　**建议学时：** 4 学时　**资源版本：** 2026.11-demo-v1 / 包版本 1　**知识包状态：** 待教研组审核

### 01 课程与任务定位

本资源包以「PLC技术及应用」中的典型工作任务「物料分拣站 I/O 分配与接线检查」为载体，面向机电一体化技术学生，按工学一体化思路组织“工作任务—学习任务—学习成果”的学习过程。

教学用物料分拣站需要接入 PLC 控制。你拿到工艺流程、工作站图纸和器件清单，但 I/O 分配表尚未完成，部分外围接线需要核对。

| 项目 | 内容 |
| --- | --- |
| 课程性质 | 专业核心课 / 中级段 |
| 课程知识包 | PLC技术及应用（待教研组审核） |
| 任务成果 | I/O 分配表、外围接线检查记录、风险确认单 |
| 教学条件 | PLC 实训室；物料分拣教学工作站；设备型号与台套数以现场为准 |

<sub>依据：PK-PLC-01 §01、PK-PLC-01 §03</sub>

### 02 学情分析与教学策略

教学对象：36 人（演示班级，基础待教师补充）。

- 以真实工作任务导入，先让学生明确“做什么、做到什么程度、凭什么验收”。
- 采用资讯—计划—决策—实施—检查—评价的工作过程，教师从讲授者转为任务设计者、巡回指导者和证据审核者。
- 将安全确认、记录留痕和版本管理嵌入任务过程，而不是最后附加。
- 对基础较弱的学生提供流程图、检查表和示范；对学有余力的学生增加排故或优化任务。

> **知识包边界**　本课程知识包是校本教学示例，不是广州市技师学院正式课程标准。课程名称/类别/阶段来自原表；章节、知识点、任务与评价由 PK-PLC-01/02 整理，需机电一体化技术教研组审核。设备型号、I/O 地址、软件版本和安全权限以现场设备说明书、实训室规程和课程负责人确认结果为准。

<sub>依据：PK-PLC-01 §01、PK-PLC-01 §03</sub>

### 03 教学目标

目标按知识、技能、职业素养三个维度表述，并在评价表中对应证据。

| 目标维度 | 目标表述（可评价） |
| --- | --- |
| 知识 | 说明 PLC 的基本组成、扫描工作过程以及输入/输出接口的作用；解释梯形图、定时器、计数器、互锁与复位的基本逻辑；说明 I/O 分配、程序注释、版本标识和备份记录的基本规范 |
| 技能 | 依据工艺流程完成物料分拣站的 I/O 分配和外围接线检查；编写并下载带注释的梯形图程序，完成手动、单步和自动运行验证；按“现象—判断—验证—结论”分析常见故障，完成程序备份与恢复验证 |
| 职业素养 | 执行急停可达、危险区域确认和强制 I/O 登记等安全要求；坚持先验证输入再验证输出、先单步再连续、每次只改变一个条件；如实记录测试条件、预期现象、实际现象和修改内容 |

<sub>依据：PK-PLC-01 §01、PK-PLC-01 §03</sub>

### 04 教学重点、难点与突破

| 项目 | 内容 | 突破策略 |
| --- | --- | --- |
| 重点 | I/O 分配与外围接线的一致性；顺序控制中的进入条件、输出动作和退出条件；单步验证与自动联调的先后关系；强制 I/O 的登记、监护和及时解除 | 用任务书、流程图、单步验证和检查表把关键动作显性化。 |
| 难点 | 把工艺流程转换为状态转移表或流程图；根据现象定位到输入信号、程序逻辑、输出执行或机械卡阻；在故障处理中保持安全回路完整，不以短接换取调试便利 | 提供故障案例、信号链排查表和教师示范，安排同伴互检。 |
| 安全 | 接线、改线、拆线前必须断电、验电并确认隔离。；上电、下载、复位和强制 I/O 前须经教师确认，保持急停可达。；不得短接急停、安全门、光栅或其他安全联锁。 | 安全交底、断电验电、教师确认和过程记录四步前置。 |

<sub>依据：PK-PLC-01 §01、PK-PLC-01 §03</sub>

### 02 关键概念与操作要点

**PLC 的基本组成与扫描过程**：PLC 由电源、CPU、存储器、输入/输出模块和通信接口等组成；运行时按输入采样、程序执行、输出刷新循环工作。理解扫描过程有助于解释输入变化与输出响应之间的时间关系。

**输入/输出类型与接线检查**：输入信号可能来自按钮、限位、光电/接近传感器等，输出可能驱动继电器、接触器、指示灯或电磁阀。接线前必须核对信号类型、公共端、电源等级和端子定义，不能仅凭线色判断。

**I/O 分配表与地址核对**：I/O 分配表应说明设备/信号名称、输入或输出类型、地址、常开/常闭状态和备注。程序中的地址必须与分配表、外围接线和工作站图纸一致；设备实际地址以设备说明书和图纸为准。

**调试安全边界与急停**：程序下载、复位和强制 I/O 前必须确认输出负载和机械动作范围，保持急停可达并设置警示。不得短接急停、安全门、光栅或其他联锁；人员不得进入未确认安全的机械动作区域。

> **来源说明**　本页知识点来自教师教学资料 / 校本示例。标为“待审核”的内容需教研组确认；设备参数以现场说明书为准。

<sub>依据：PK-PLC-01 §01、PK-PLC-01 §03</sub>

### 03 常见错误与安全提醒

- 把“能运行”当作唯一验收标准，缺少过程记录与自检。
- 未核对 I/O 地址、传感器类型或公共端就下载程序。
- 强制输出后未解除，复位测试不完整。
- 为调试方便短接急停、安全门或联锁。
- 备份文件没有版本、来源和恢复验证。

- [ ] 接线、改线、拆线前必须断电、验电并确认隔离。
- [ ] 上电、下载、复位和强制 I/O 前须经教师确认，保持急停可达。
- [ ] 不得短接急停、安全门、光栅或其他安全联锁。
- [ ] 机械动作前确认人员撤离危险区域，运行中不得进入。
- [ ] 发生碰撞、异常停止或安全装置动作时，先保护现场并报告。

<sub>依据：PK-PLC-01 §01、PK-PLC-01 §03</sub>

### 03 操作步骤

1. 阅读工艺流程和图纸，列出输入/输出设备及信号类型。

2. 为每个信号分配地址，注明常开/常闭、公共端和备注。

3. 断电核对端子、线号和公共端，记录与图纸不一致处。

4. 完成上电前安全检查，经教师确认后做输入信号逐点验证。

每完成一个关键步骤，先在记录表写下条件、预期和实际，再进入下一步。

<sub>依据：PK-PLC-01 §01、PK-PLC-01 §03</sub>

## 知识库依据

- **[PK-PLC-01 §01] 物料分拣站PLC控制系统安装与调试 · 典型工作任务与交付物**
  > 教学任务来自物料分拣工作站的安装与调试：依据工艺流程完成I/O分配、外围接线检查、控制程序编写与下载，在手动和单步模式下验证传感器、执行器和顺序动作，再完成自动运行联调。交付物包括I/O分配表、带注释的程序、单步验证记录和异常处理记录。
- **[PK-PLC-01 §02] 物料分拣站PLC控制系统安装与调试 · 程序设计与调试任务链**
  > 先用状态转移表或流程图梳理每一步的进入条件、输出动作和退出条件，再完成I/O分配和程序框架。
- **[PK-PLC-01 §03] 物料分拣站PLC控制系统安装与调试 · 安全与强制I/O边界**
  > 程序下载前确认输出负载和机械动作范围，调试区设置警示并保持急停可达。强制I/O必须按现场要求登记、复核并有人监护，用后及时解除；不得为调试方便短接急停、安全门、光栅或其他联锁。涉及机械动作前必须确认人员撤离危险区域。
- **[PK-PLC-01 §04] 物料分拣站PLC控制系统安装与调试 · 评价证据与故障分析**
  > 评价应覆盖I/O分配准确性、程序逻辑、注释与版本、单步验证完整性、故障定位过程、安全操作和协作表达。常见问题包括输入信号类型判断错误、定时与顺序关系混乱、强制输出未复位、未做复位测试以及把“能自动运行”当作唯一标准。
- **[PK-PLC-02 §01] PLC控制程序备份、恢复与版本管理 · 典型维护任务与交付物**
  > 典型任务是核对控制设备与程序版本，完成程序、参数和必要的画面工程备份，按命名规则归档，并在教学设备上做恢复验证。交付物包括设备与版本核对表、备份文件清单、恢复验证记录和变更说明。备份不是“复制一个文件”，而是能在授权范围内被找到、识别、校验和恢复。
- **[PK-PLC-02 §02] PLC控制程序备份、恢复与版本管理 · 备份与恢复工作页流程**
  > 工作页可按“核对—连接—导出—校验—归档—恢复—验证”组织。连接前确认通信参数和权限；导出后核对文件大小、时间戳和工程内容；恢复前再次确认设备与版本；恢复后检查程序块、参数、通信和关键动作，并记录差异。每个步骤都要有证据，最好配合截图、校验值或教师确认。
- **[PK-PLC-02 §03] PLC控制程序备份、恢复与版本管理 · 安全、授权与数据边界**
  > 维护前按现场要求停机、隔离并上锁挂牌，确认不会意外启动；涉及带电检查时由具备资质的人员执行。程序、参数、网络配置和工艺数据可能属于学校或合作单位资产，应按授权访问和存储，不擅自外传或上传到未经批准的网盘、聊天工具或第三方平台。
- **[PK-PLC-02 §04] PLC控制程序备份、恢复与版本管理 · 评价证据与常见风险**
  > 评价可检查核对表、文件命名、备份完整性、校验记录、恢复验证和变更说明。常见风险包括备份文件没有版本、只保存到个人电脑、恢复前未确认设备、恢复后未做动作验证，以及把维护记录写成“已完成”而缺少证据。
