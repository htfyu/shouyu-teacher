## 三、为什么保留原值

- 原始 Excel 是审计对象，不能为了“看起来干净”而静默改写；
- 若直接修正 `programs-data.js`，会失去“原表错在哪里”的证据；
- 系统采用“原值 + 建议修订 + 界面警示 + 知识包只用修订后来源”的方式，既保留证据，又避免错误进入质量评分；
- 修订依据写入 `js/curriculum-data.js` 的 `SOURCE_CORRECTIONS`，页面可查看原值、建议、方法、日期和状态。

## 五、页面与质量分如何体现

- 课程详情：显示原表来源、错配警示、建议修订；
- 智能备课中心：显示“来源核验”块，含原值、建议、方法、状态；
- 质量检测：知识点来源覆盖进入 B 层；但来源覆盖率明确标注“不代表事实正确率”；
- 未审核知识包 + 未专家确认时，综合分封顶 84；
- 任何页面都不显示“已通过学校审核/专家认证”，除非有真实审核记录且知识包状态为 approved。
