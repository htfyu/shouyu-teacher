# 教学应用成效模块说明

> 路由：`#/impact`  
> 实现：`js/impact-engine.js`、`js/impact-store.js`、`app.js`  
> 原则：没有真实数据就显示“尚未采集”；不预填、不模拟、不把试用记录包装成学校认证。

## 一、记录什么

每条记录包含：

- 教师匿名代号（不填真实姓名）；
- 试用课程；
- 试用日期；
- 传统备课时间（分钟）；
- 使用授渔后的备课时间（分钟）；
- 生成资源数量；
- 人工修改比例（0—100%）；
- 教师评价（1—5）；
- 专家审核结果（未审核 / 通过 / 有条件通过 / 退回修改）；
- 审核人/教研组（可匿名）；
- 备注；
- 测量/记录时间；
- 来源（教师记录 / 导入 / 匿名导出）。

## 二、必须有真实测量

新增记录时必须勾选：

> 我确认这些数字来自实际测量或学校/教研组记录，不是模拟数据。

取消勾选不能保存。系统没有内置示例记录；首次进入显示“还没有真实应用数据”。

## 三、聚合与图表

- 参与教师：按匿名代号去重；
- 试用课程：按课程去重；
- 生成资源：累加；
- 平均传统/授渔时间：只统计同时填写两者的记录；
- 平均节省时间 = 传统 - 授渔；
- 平均节省比例 = 每条记录 `(传统-授渔)/传统` 的平均；
- 平均人工修改比例、教师评价均值；
- 专家审核通过/已审核数。

图表只展示真实记录均值；没有数据时显示空态，不画 0 或假柱状图。

## 四、导入 / 导出 / 匿名化

- **导出 JSON**：原始记录 + schema + 导出时间；
- **导出 CSV**：中文表头，字段包含时间、课程、时间节省、修改比例、评价、专家结果；
- **匿名导出 JSON**：
  - 教师代号替换为“教师01…”；
  - 清空备注和审核人；
  - 不修改本机原始记录；
- **导入 JSON**：校验每条记录；替换当前本机记录；导入前弹窗确认；
- **字段模板 CSV**：无数据时可下载空白表头，作为学校记录模板。

## 五、存储与备份

- IndexedDB `shouyu_impact_v1`；
- 兼容回退 localStorage `shouyu.impact.v1`；
- 完整备份包含 `impact.records`；
- 恢复备份会替换本机记录；
- 删除本机数据会清空应用成效库；
- 不是云同步，不跨设备。

## 六、边界

- 本模块不自动采集教师行为，不读取课堂数据；
- 不计算“提升百分比”作为宣传结论，除非学校提供真实对照记录；
- 不把单次试用等同于“学校应用证明”；
- 不把教师评价等同于专家审核；
- 数据可能含备注等自由文本，导出前请确认脱敏；匿名导出会清空备注/审核人，但课程名称仍保留；
- 真实试点需要学校立项、知情同意和正式数据管理流程。

## 七、建议的学校试点记录方式

1. 同一课程、同一任务，教师先按传统方式记录一次实际备课时间；
2. 使用授渔生成 10 类资源，记录实际修改时间；
3. 由教师填写人工修改比例、评价和问题；
4. 教研组审核后填写专家结果；
5. 保存原始记录，导出匿名数据用于汇总；
6. 至少完成 3 门课程、3 位教师后再做对比结论。
