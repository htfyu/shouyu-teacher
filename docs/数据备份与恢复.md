# 数据备份与恢复

## 1. 数据存放在哪里

| 数据 | 存储位置 |
|---|---|
| 对话、成果、引用、反馈 | IndexedDB `jiangbei_v2` → `conversations` |
| 自定义知识 | IndexedDB → `knowledge` |
| 资料解析文本 / 分块 | IndexedDB → `files` |
| AI 设置 / 文件大小上限 | IndexedDB → `settings` |
| 专业数据库修订 / 课程资料 / 自建记录 / 隐藏标记 | IndexedDB `shouyu_programs_v1` → `catalog`；兼容回退 localStorage `shouyu.programs.v1` |
| 教学资源包 / 版本 / 质检 / 审核状态 | IndexedDB `shouyu_studio_v1` → `bundles`；兼容回退 localStorage `shouyu.studio.v1` |
| 质检权重 | localStorage `shouyu.quality.weights.v1` |
| 兼容回退 | localStorage `jiangbei.workspace.v2`（小于约 4.2MB 时） |
| AI 代理访问口令 | 仅 sessionStorage，当前标签页 |

**IndexedDB 不是跨设备同步。** 换浏览器、换设备、清理站点数据都会丢失；请用备份文件迁移。

## 2. 导出

「AI 与数据设置」→“本机数据”：

- **导出完整备份**：对话 + 自定义知识 + 资料 + 设置 + 专业数据库修订 + 教学成果库（不含 AI 模型 Key，也不含代理口令）；
- **仅导出对话**：只导出对话数组；
- 历史页的“导出备份”等价于完整备份。

备份文件名包含时间，格式为 `jiangbei.backup.v2`。文件可能包含教师输入的教学内容，请存放在学校批准的位置。

## 3. 恢复

1. 打开「AI 与数据设置」；
2. 点“导入备份”，选择 JSON；
3. 系统校验 schema、数组类型并显示对话 / 知识 / 资料数量；
4. 确认“覆盖并恢复”；
5. 页面自动重新加载。

恢复会替换当前 IndexedDB 中的对话、自定义知识、资料与设置；如果备份含专业数据库修订或教学成果库，也会一起恢复。**建议先导出当前备份。**

专业数据库还有独立的“管理数据 → 导出修订 / 导入修订”，用于只迁移专业库，不影响对话与资料。

旧格式 `jiangbei.workspace.v2` 也能通过校验；缺少的字段按空数组处理。

## 4. 删除本机数据

设置页“删除本机数据”会：

- 清空 IndexedDB 的 conversations / knowledge / files / settings / meta；
- 清空专业数据库修订库 `shouyu_programs_v1`；
- 清空教学成果库 `shouyu_studio_v1`；
- 删除 localStorage 中的工作区、AI 设置、专业库兼容修订、成果库兼容数据与质检权重；
- 删除 sessionStorage 中的代理口令；
- 重新加载页面。

不会删除：第三方模型服务按其政策保留的请求日志（本项目无法控制）；浏览器自身的下载文件；备份 JSON 文件。

## 5. 使用建议

- 每周或每次重要修改后导出完整备份；
- 备份文件不要发到公开群聊或未授权云盘；
- 恢复前确认来源可信，避免把别人的自定义知识导入自己的库；
- 关闭公共电脑前删除本机数据；
- 如果浏览器提示存储配额不足，先导出备份，再清理旧资料或旧对话。

## 6. 异常恢复

- 页面刷新中断生成：启动时检查 `pending` / `typing` 消息，转为“上次生成被中断”的说明消息；
- IndexedDB 打不开：回退 localStorage 兼容模式，页面仍可用；
- localStorage 容量不足：完整数据仍写 IndexedDB（如果可用）；
- 备份格式错误：界面明确报错，不会部分覆盖；
- 恢复失败：当前数据保持不变（恢复事务失败时回滚）。
