# 知识库管理说明

## 1. 结构

```js
{
  id: "PK-CNC-01",                 // 全局唯一
  title: "数控车削典型工作任务与教学要点",
  category: "专业·数控技术",
  specialty: "数控技术",
  course: "数控车削编程与加工",
  source: "校本示例 · 教学团队整理",
  author: "授渔教研示例",
  published: "2026-11-16",
  version: "校本示例 v1.0",
  updated: "2026-11-16",
  scope: "适用于……；不替代正式标准。",
  summary: "一句话摘要",
  tags: ["数控", "对刀"],
  sections: [
    { id: "PK-CNC-01-1", no: "01", title: "章节标题", text: "正文", bullets: ["要点"] }
  ]
}
```

内置材料位于 `js/knowledge.js` 与 `js/knowledge-packs.js`；自定义材料存在于 IndexedDB。

## 2. 页面操作

- **浏览 / 检索**：知识库页按分类筛选，支持标题、标签、正文检索；引用可回溯到章节。
- **管理知识库**：页头按钮进入管理态。
- **新增材料**：填写名称、分类、专业、课程、来源、作者、版本、发布时间、适用范围、摘要、标签、正文。
- **编辑**：只允许编辑自定义材料；内置材料点“复制为自定义”后修改。
- **删除**：仅自定义材料；删除后检索和引用立即移除。
- **批量导入**：JSON 数组或 `{docs:[...]}`；单次最多 100 份；格式不完整、重复或含疑似个人信息的条目会跳过。
- **导出自定义库**：下载 `jiangbei.knowledge.v1` JSON。
- **分块**：正文用 `## 小节标题` 组织；没有标题时按语义边界自动分块，不直接丢弃长文。
- **重复检测**：标题或前 500 字正文相同即视为重复，阻止保存。
- **版本记录**：编辑自定义材料时保存最近 5 个旧版本快照；管理列表显示版本数。

## 3. 13 个专业包

电气自动化、PLC 技术、数控技术、汽车维修、工业机器人、机械加工、焊接技术、电子技术、计算机技术、建筑工程、化工技术、新能源技术。

每个专业 2 份材料 × 4 章节，来源明确标注校本示例，不伪造 GB / ISO / 企业标准号。操作级安全仍只覆盖电工 / PLC；其他专业包提供教学安全提示，不能替代现场规程。

## 4. 检索

本地混合检索：

1. 中文 bigram / trigram、英文缩写与标题 / 标签 / 正文匹配；
2. 场景权重（教案、评价、安全、听评课）；
3. 领域概念扩展（例如“互锁”→“联锁 / 自锁 / 接触器”）；
4. 按分数排序，引用格式 `文档编号 §章节号`。

**不是神经网络向量检索**。没有嵌入模型或向量库；对同义改写、长距离语义的召回有限。若需要真正向量检索，应增加嵌入服务与向量库，并保留当前词法检索作为兜底。

## 5. 来源与真实性

- 内置材料和专业包均为**校本示例**，不是学院正式文件；
- 引用只使用本次上下文提供的来源；未知引用被丢弃并提示；
- AI 改写模块如果没有有效引用，会提示“AI 引用检查”；
- 正式使用前必须替换或审核课程、设备、企业标准、评价权重与安全条款。

## 6. 文件加入知识库

资料中心解析出的文件可“加入知识库”：

- 只保存提取后的文本与分块，不保存原始文件；
- 若检测到个人信息，必须先脱敏，保存的是脱敏文本；
- 生成自定义文档，来源标注“教师上传”，范围标注“未经学校审核”；
- 删除资料时，如果它已加入知识库，对应自定义文档一并删除。

## 7. 替换内置知识库

可编辑 `js/knowledge.js` 或 `js/knowledge-packs.js` 后重新部署。自定义材料不需要改代码，直接在页面维护即可。引用、检索、下载、来源面板会自动更新。
