# 工作型 UI 响应式检查报告

> 日期：2026-11-17  
> 视口：1920 / 1440 / 1024 / 768 / 390  
> 检查方式：Microsoft Edge headless + 实际页面截图 + `scrollWidth - clientWidth` 计算 + 控制台错误监听。

## 一、总体结果

| 视口 | 横向溢出 | 控制台错误 | 布局结果 |
|---|---|---|---|
| 1920×1000 | 0 | 0 | 首页主栏 + 右栏；备课三栏；质检三栏；知识库分类 + 列表 + 阅读 |
| 1440×1000 | 0 | 0 | 同上；内容最大宽度收敛，长文可读 |
| 1024×900 | 0 | 0 | 首页单栏 + 右栏三块；备课左右两栏、资料下移；质检两栏、建议下移；知识库三栏压缩 |
| 768×900 | 0 | 0 | 侧栏抽屉；首页单栏；备课单列；质检单列；知识库分类折叠为下拉 |
| 390×844 | 0 | 0 | 单列工作流；按钮不溢出；输入框可正常聚焦；长文自然滚动 |

逐页检查：`/`、`/programs`、`/kb`、`/studio`、`/quality`、`/graph`、`/files`、`/portfolio`、`/impact`、`/demo`。

## 二、各页面响应式处理

### 首页

- 1920 / 1440：主栏 + 286px 右侧工作栏；
- 1024：右侧三块移到主栏下方，排成三列；
- 768 / 390：单列；日期、问候、两个主操作依次排列；继续编辑按钮占满宽度；
- 快速开始：桌面 5 列，平板 3 列，手机 2 列（最后一项跨两列）。

### 智能备课中心

- 1920 / 1440：300px 配置 + 自适应文档 + 286px 资料栏；
- 1280 以下：资料栏移到下方，三块并排；
- 1024 / 900 以下：单列，配置 → 文档 → 资料；
- 手机：顶部上下文 — 配置表单 — 生成按钮 — 结果文档；
- 生成成功后，手机自动滚动到文档区，避免停在配置底部；
- 右侧资料栏提供“收起资料/展开资料”，收起后编辑器占满宽度。

### 质量检测

- 1920 / 1440：左问题清单 + 中原文 + 右建议；
- 1024：两栏，建议下移；
- 900 以下：单列，**问题清单 → 问题分析/建议 → 原文**；
- 手机隐藏“待教师确认”长列表，保留“逐项确认（5 项）”入口；
- 文档区不再限制高度，避免嵌套滚动。

### 专业知识库

- 1920 / 1440：190px 分类 + 列表 + 430px 阅读；
- 1024：阅读区 360px；
- 900 以下：分类在上、列表与阅读单列；
- 700 以下：分类栏隐藏，改用原生 `<select>`；列表与阅读依次排列；
- 资料正文可自然滚动，不压缩字号。

### 专业体系 / 知识图谱 / 资料中心 / 成果 / 应用成效 / 演示

- 统计改为单行摘要带，手机横向滚动而不挤压；
- 专业目录保留左树右内容，手机切换为目录在上；
- 图谱画布保留最小高度，手机横向查看；
- 文件行、成果行在手机隐藏次要元信息，操作按钮保留；
- 表格横向滚动；
- 弹窗宽度使用 `min(920px, calc(100vw - 24px))`，不超出屏幕。

## 三、移动端专门调整

1. 知识库分类改为下拉，首屏直接看到资料列表；
2. 质量检测重排为“问题 → 建议 → 原文”，符合手机阅读顺序；
3. 备课生成后自动定位文档；
4. 主操作按钮不换行、不超出屏幕；
5. 侧栏变为抽屉，打开后可用遮罩关闭；
6. 输入框使用系统滚动，不固定底部，避免虚拟键盘遮挡；
7. 长文档不使用固定高度嵌套滚动。

## 四、已知限制

- 未做真机 iOS / Android 触摸测试；
- 虚拟键盘行为只通过布局推断，未在真机验证；
- 1920 下部分页面内阅读区仍有较多留白，后续可按实际使用调整最大宽度；
- 知识图谱在 390px 下需要横向查看，尚未改为可缩放画布。

## 五、结论

五个视口均无横向溢出、无新增控制台错误。三栏工作区在 1024 以下主动降级为两栏/单栏，没有把桌面三栏强行压进手机屏幕。
