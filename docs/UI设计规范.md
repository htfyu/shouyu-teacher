# 授渔 · UI/UX 设计规范（V2.2 · 编辑部工作台版）

> 2026-11-17 视觉改造：从“通用 AI SaaS 后台”转为“编辑部式排版 + 专业工作室 + 纸面质感 + 模块颜色识别”。

> 只调整样式、排版、图标表现、色彩与微文案；路由、数据结构、AI 引擎、存储、隐私、文件解析、生成与质检逻辑未改。

## 1. 设计定位

**一个由教师长期使用的专业教学工作台，而不是宣传 AI 能力的控制台。**

四个关键词：

- **温暖**：米白纸面、深墨文字、暖金行动色；
- **专业**：衬线标题、清晰的层级、真实的来源与审核状态；
- **灵动**：八个模块各有颜色与版式，不再全站一套蓝色；
- **克制**：不做玻璃拟态、霓虹、粒子、夸张渐变和装饰性动画。

## 4. 字体与排版

- 正文：`Source Han Sans SC / Noto Sans SC / PingFang SC / Microsoft YaHei`。
- 页面主标题、课程包标题、质量分数：`Noto Serif SC / Source Han Serif SC / Songti SC`。
- 数字与参数：等宽回退 `Cascadia Code / Consolas`。
- 主页面标题：28—40px，700，行高 1.2，字距 `-0.025em`。
- 模块标题：19—22px，650。
- 卡片标题：15—18px，600。
- 正文：13—14px，行高 1.62。
- 辅助说明：11—12.5px；小号文字不低于 `--muted-2`（4.54:1）。
- 标题下有一条 34×2px 的模块色短线，作为编辑部的“栏目线”，不使用大面积装饰。

## 5. 布局去模板化

### 工作台

- 暖金纸面 Hero：欢迎语、当前工作、开始备课按钮；
- Hero 右侧是便签式状态卡，不是统计卡；
- 最近编辑、待处理、专业目录、知识库基线四块使用不同底色与边线；
- 统计只在卡片内部出现，不占据第一视觉。

### 专业体系数据库

- 统计改为一条目录索引带，不再是四张同款大卡；
- 四级目录：系 → 组 → 专业 → 课程；
- 左侧树、右侧内容；蓝色只标记层级和当前位置。

### 专业知识库

- 绿色“书脊”卡片，卡片右上角有两条细线作为索引记号；
- 来源、版本、审核状态放在标题附近；
- 分类使用书签式标签。

### 智能备课中心

- 顶部先显示五阶段流程：选课程 → 定任务 → 生成资源 → 检查质量 → 审核导出；
- 左侧条件卡（陶土橘顶线），右侧任务与资源准备；
- 结果区先质量依据，再问题与建议；人工编辑按钮始终在结果头部；
- 编辑器预览使用极浅横向纸纹，不覆盖正文。

### 质量检测中心

- 统计压缩为一条细带；
- 评分、依据、问题位置、教师审核项在同一视觉层级；
- 通过 / 警告 / 待人工确认使用统一功能色，不用紫色替代语义；
- 不使用夸张评分环。

### 知识图谱

- 画布使用浅点阵纸面；
- 课程、章节、知识点、任务用不同线框与浅底；
- 选中节点为湖水青实底，文字反白；
- 只画有数据依据的边。

### 资料管理中心

- 文件行左侧有雾霾蓝细条；
- 文件类型、解析进度、预览状态并列；
- 上传区是虚线纸面，不使用大面积说明卡堆叠。

### 教学成果管理中心

- 成果卡采用档案条目：左侧橄榄绿细条、版本/审核/质检标签；
- 优先显示“可导出”状态；
- 版本与历史放在同一档案上下文。

## 6. 侧边栏

- 背景为暖灰纸面 `#F2EDE3`，与内容纸面区分但不冷；
- 每个一级菜单有独立主题色图标；
- 当前项：对应浅色底 + 左侧 3px 色条 + 深色文字；
- 次级说明/计数为深灰，不与图标抢色；
- 分组之间以自然留白分隔，不使用统一蓝色图标；
- 保留桌面折叠（76px）与 ≤960px 抽屉；
- 品牌标识保持黑白莫比乌斯鱼钩，不重新绘制。

## 7. 卡片与组件

允许的五种卡片：

1. **纸面卡**：内容面板，1px 暖边框；
2. **档案卡**：左侧 3px 模块色条，用于成果、文件、质量报告；
3. **书脊卡**：知识库资料，左侧厚 4px 绿色边；
4. **便签卡**：Hero 状态、审核提示，浅暖底 + 左侧色条；
5. **索引带**：专业体系统计，横向分隔，不用卡片阴影。

统一保留：

- 按钮高度 32—38px，圆角 8px；
- 输入框圆角 8px，焦点环 3px 浅色；
- 页面模块间距 18—28px；
- 卡片悬停只改变边框/底色，不做位移和放大；
- 图标使用简洁线性 SVG，颜色跟随模块。

## 8. 动效

- 导航切换、卡片悬停、展开折叠、进度、图谱节点：120—250ms；
- 使用 `--ease: cubic-bezier(0.22, 1, 0.36, 1)`；
- 不使用粒子、光效、漂浮、视差；
- `prefers-reduced-motion: reduce` 时关闭过渡与动画。

## 9. 微文案

优先自然、具体、教师视角：

- “正在整理课程资料……”
- “已找到相关教学内容。”
- “这份教案已经整理好了。”
- “还有两个教学环节需要完善。”
- “保存好了，下次可以继续修改。”
- “这部分内容建议由专业教师确认。”

减少：

- “AI 智能赋能教学”
- “AI 正在思考”
- “魔法生成”
- “一键 AI 创作”
- “智能化全面升级”

技术边界仍必须保留：

- AI/增强模式的数据传输说明；
- “规则评分不是学校官方认定”；
- “知识包待教研组审核”；
- “无数据时不显示应用成效”。

## 10. 可访问性与响应式

- 正文对比度 ≥ 4.5:1；按钮文字 ≥ 4.5:1；
- 颜色不是唯一信息载体，状态同时有文字；
- 焦点可见，键盘可操作；
- 1920 / 1440 / 1024 / 768 / 390px 无横向溢出；
- 移动端侧栏为抽屉，主要操作在首屏可见；
- 小屏标题 27px，Hero 27px，按钮不换行成两行。

## 11. 验收清单

1. 八个板块有明确颜色识别；
2. 导航颜色与页面内部一致；
3. 页面底色为暖纸面，不再是冷灰；
4. 各页面排版有性格差异；
5. AI 宣传式微文案明显减少；
6. 职业教育平台的专业性保留；
7. 原有功能、路由、存储、质检、AI、文件解析正常；
8. 主要按钮、表单、审核、导出可用；
9. 文字对比度达标；
10. 1920 / 1440 / 1024 / 768 / 390 正常；
11. 单元测试与 E2E 实际执行结果记录在测试报告；
12. 控制台无新增错误。
