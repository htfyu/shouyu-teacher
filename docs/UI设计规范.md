# 授渔 · UI/UX 设计规范（V2.1）

> 本次改造只调整样式、布局与交互表现，不改路由、数据结构、接口、权限与业务逻辑。

## 1. 设计方向

- **Linear 式留白与信息密度**：明确层级，减少无用装饰。
- **Apple 式精致度**：细边框、克制阴影、完整交互状态。
- **SaaS 工作台组织方式**：导航分组、页面头部、统一卡片、统计与工具栏。
- 保留黑白灰主色，以低饱和蓝作为唯一主交互色。

## 3. 字体

- 字体栈：`Inter / Source Han Sans SC / Noto Sans SC / PingFang SC / Microsoft YaHei / system-ui`。
- 原衬线标题统一改为无衬线；`--serif` 在主题层指向同一无衬线字体栈，减少混用。
- 主页面标题：28—32px，600—650，行高 1.2。
- 模块标题：19—22px，600。
- 卡片标题：15—17px，600。
- 正文：13—14px，行高 1.6—1.75。
- 辅助说明：11—12.5px，颜色 `--muted`。
- 标签 / 元信息：10—11.5px，使用 `--muted-2`，但不再使用过浅颜色。

## 4. 布局规范

| 场景 | 规范 |
|---|---|
| 左侧导航 | 默认 276px；桌面可折叠为 76px；≤960px 为抽屉 |
| 内容页最大宽度 | 1460px；统一左右内边距 `clamp(22px, 3vw, 44px)` |
| 页面头部 | 主标题 + 简介 + 右侧信息卡；≤1080px 单列 |
| 双栏内容区 | 主栏 + 280—350px 辅助栏；≤1080px 单列 |
| 卡片网格 | `repeat(auto-fill, minmax(290px, 1fr))` |
| 间距 | 8 / 12 / 16 / 20 / 24 / 32；页面模块间距 18—28 |
| 顶栏 | 58px；≤960px 56px；只保留全局操作，页面标题下移到内容区 |

## 5. 组件规范

### 按钮
- 高度 36px；小按钮 30—32px。
- 圆角 8px；默认白色 + 浅边框；主按钮蓝色；幽灵按钮透明。
- 悬停：边框加深 + 轻微阴影；按下：1px 位移；禁用：45% 透明度。

### 输入 / 表单
- 高度 40px；圆角 8px；边框 `--line`。
- 聚焦：蓝色边框 + 3px 淡蓝外环。
- 标签 12px / 600；提示 11.5px；错误使用红色边框与文字。

### 卡片
- 白底、浅灰边框、12px 圆角、微阴影。
- 内边距 16—20px；标题 15—17px；元信息 10—11px。
- 悬停：蓝色系边框 + 柔阴影 + 1—2px 上浮。
- 选中：蓝色描边 + 淡蓝底，不再使用纯黑块。

### 导航
- 分组：工作区 / 记录 / 系统。
- 项目高度 40px、字号 13px；激活：淡蓝底 + 蓝色左侧标识。
- 折叠后保留图标与 `title` / `aria-label`。

### 页面头部
- 标题、简介、右侧信息卡、统计卡依次排列。
- 统计卡统一 4 列；≤1080px 2 列。
- 主操作放在右上方或页面工具栏，保证首屏可见。

## 6. 重点页面

- **资料中心**：主栏上传 / 进度 / 文件列表；右栏格式、限制、处理规则、指南；下方资料库。
- **知识库**：页面头部 + 统计 + 统一检索工具栏（通用分类 / 专业方向分组）+ 卡片网格。
- **模板库**：浅边框模板卡、类型图标、统一高度、底部操作区。
- **历史**：页头 + 统计 + 搜索 / 分类 / 批量操作工具栏 + 卡片列表。
- **设置 / 教学配置**：主栏配置面板 + 右侧安全与状态卡片；表单统一。
- **专业数据库**：左侧四级体系树 + 右侧内容区；≤1080px 切换为三个级联选择框；课程资源使用宽弹窗，左右“内容 / 元信息与来源”布局，≤1080px 单列。
- **编辑器**：模块 / 表单 / 预览三栏；窄屏堆叠，不隐藏预览。

## 7. 响应式断点

- 1180px：页面头部与右侧栏收缩。
- 1080px：双栏变单栏；统计 2 列；编辑器堆叠。
- 960px：侧栏变抽屉；顶栏降高；提示浮层移到下方。
- 700px：卡片单列或双列；筛选分组单列；移动顶栏只留图标。
- 460px：场景卡单列；输入区与按钮适配。

## 8. 交互状态

- 所有按钮、卡片、导航、筛选、输入均有 hover / focus-visible / active / disabled 规则。
- 文件上传：进度、成功、失败 + 重试。
- AI：流式、停止、失败回退、截断提示。
- 空状态、错误状态、成功 Toast 统一视觉。
- 动效控制在 150—300ms，避免影响性能。

## 9. 验收

- 1920 / 1440 / 1024 / 768 / 390 宽度无横向溢出。
- 45 项浏览器 E2E、72 项单元测试通过。
- 路由、生成、编辑、导出、文件解析、历史、备份、AI 模式保持可用。
- 控制台 0 错误。

实现文件：

- `assets/ui-refresh.css`：主题层与组件覆盖；
- `assets/styles.css`：原有基础样式与业务组件；
- `js/app.js`：导航分组 / 折叠、资料中心结构、知识库工具栏、模板标识、历史工具栏。
