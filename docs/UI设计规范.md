# 授渔 · UI/UX 设计规范（V3.0 · 课程与项目工作型）

> 2026-11-17 工作型重构：从展示型页面转为教师长期使用的教学工作空间。

> 只调整前端结构、样式、排版与交互表现；路由、数据、存储、AI、知识库、质量检测和编辑器逻辑未改。

## 1. 定位

**教师每天打开、编辑、检索、审核和保存教学成果的软件，不是产品宣传页。**

原则：

- 真实工作内容优先，系统规模数字退后；
- 中性底色为主，模块色只做识别；
- 一个统一品牌主操作色；
- 列表、表格、分栏、编辑区和阅读区优先于卡片；
- 减少装饰，保留适度品牌灵动感；
- 长时间使用不疲劳。

## 2. 基础色

完整 Token 见 [视觉设计/色彩Token表.md](视觉设计/色彩Token表.md)。

- 页面：`#F7F6F1`
- 内容：`#FFFFFF`
- 次级：`#F1F0EB`
- 正文：`#30332F`
- 次级文字：`#71736F`
- 辅助：`#92938D`
- 边框：`#E7E5DD`
- 品牌操作色：`#4A5F52` / 深色 `#34473A`

八模块颜色：工作台金、专业蓝、知识绿、备课橘、质检紫、图谱青、资料雾霾蓝、成果橄榄绿。

**只用于导航图标、当前项细条、分类标签和少量状态辅助，不做页面主题。**

## 3. 字体

- 正文：Source Han Sans SC / Noto Sans SC / Microsoft YaHei，14px，行高 1.58；
- 页面主标题：Noto Serif SC / Source Han Serif SC / Songti SC，24—30px；
- 工作区标题：16—20px；
- 列表标题：13px / 600；
- 辅助文字：12px；
- 微型标签：10—11px，只用于非关键信息；
- 不加载外部字体。

## 4. 布局体系

| 场景 | 规范 |
|---|---|
| 侧栏 | 260px；≤960px 抽屉 |
| 顶栏 | 56px，只放全局操作 |
| 页面最大宽度 | 1360—1600px，按信息密度调整 |
| 页面内边距 | `clamp(20px, 3vw, 40px)` |
| 双栏工作区 | 主栏 + 280—320px 辅助栏 |
| 三栏工作区 | 280—300px + 自适应主栏 + 280—300px |
| 页面区块间距 | 22—28px |
| 表格 | 横向滚动，不压缩列 |
| 卡片 | 只在独立分组、状态区分或交互时需要 |

## 5. 导航

### 四个核心入口

1. 工作台；
2. 我的课程（课程列表 + 课程工作空间）；
3. 备课工作室（六步流程 + 项目文档工作区）；
4. 我的成果（项目、版本、审核、导出）。

### 更多功能

专业数据库、质量检测历史、专业知识库、知识图谱、资料中心、模板库、教学应用成效、历史记录、系统设置、使用说明、新建对话放入“更多功能”折叠组。质量检测保留独立入口，同时嵌入备课项目右侧面板和成果审核。

### 入口语义

- **开始备课 / 新建备课**：一律进入六步备课流程；没有选课之前不预选 PLC。
- **新建对话**：只创建教学对话，不承担完整备课。
- 侧栏常驻“开始备课”；工具栏不出现同名不同行为的按钮。
- 从专业与课程、课程详情、教学资源、常用课程进入时，自动带入课程/章节/任务/参考材料。

## 6. 四大核心页面

### 5.1 首页：教师日常工作台

- 顶部：日期、问候、当前工作状态、新建备课/课程目录；
- 主栏：继续上次备课、最近编辑、我的常用课程、快速开始；
- 右栏：今日待处理、最近文件、提醒；
- 不出现大型宣传 Hero、四张系统统计大卡或产品功能卡片墙；
- 当前成果、待审核数、必须修改问题等只在有实际意义时出现。

### 6.1 备课工作室：六步流程 + 项目工作区

**六步：**

1. 选择专业和课程；
2. 选择教学章节及典型工作任务；
3. 配置教学对象、学时、教学条件；
4. 确认并生成 10 类资源；
5. 编辑并执行质量检测；
6. 保存、审核及导出。

每步只显示当前需要填写的内容；支持上一步、保存草稿、继续草稿；切换步骤不丢数据。新建备课第一步不预选具体课程。

**生成后的项目工作区：**

- 左栏：项目文档目录（10 类文档）；
- 中栏：当前文档正文、元信息和编辑入口；
- 右栏：质量 / 资料 / 属性 / AI 建议，按需切换；
- 顶部：课程上下文、项目名称、保存状态、编辑/质检/导出；
- 质量检测嵌入右栏，点问题定位原文，不再强制跳转；
- AI 只是右栏工具，不占页面主体；
- 小屏按“项目头 → 文档目录 → 文档正文 → 辅助面板”单列。

### 6.2 质量检测：审阅工作区

- 左栏：问题清单、严重度筛选、待教师确认项；
- 中栏：真实教学文档，问题位置高亮；
- 右栏：问题描述、规则、位置、修改建议、人工审核状态；
- 支持：打开编辑器、应用结构修复、上一条/下一条、忽略非关键提醒、恢复忽略、重新检测、完整报告；
- 分数只在文件条上以小号显示，不作大面板；
- 忽略只影响提醒，不改变质检分数。

### 6.3 教学资源：检索 + 阅读

- 左栏：通用分类 / 专业方向；
- 中栏：资料列表（标题、分类、版本、更新时间、节数）；
- 右栏：资料正文、来源、版本、审核状态、打开全文、用于备课；
- “用于备课”把材料作为参考来源带入六步流程；
- 移动端分类改为下拉选择，列表与阅读区单列。

## 7. 其他页面

- 专业体系：左侧层级目录 + 右侧内容；
- 知识图谱：节点/连线为数据主体，无数据不连线；
- 资料中心：上传区 + 文件列表 + 解析状态；
- 教学成果：档案列表 + 版本/审核/导出；
- 教学应用成效：真实记录与对比，未采集不显示假图；
- 演示：固定 PLC 案例，无模型密钥也能运行。

## 8. 公共组件

### 按钮

- 高度 32—36px，圆角 6px；
- 主按钮 `--brand`，次按钮白底边框，文本按钮无底色；
- 危险操作使用 `--danger`，不与品牌色混用；
- 禁用态保留文字，透明度 40%。

### 输入 / 选择

- 高度 34px，圆角 6px，1px 边框；
- focus 2px 品牌色轻环；
- 标签在上，提示在下；
- 不把说明文字塞进 placeholder。

### 列表 / 表格

- 行高 44—56px，分隔线 1px；
- 悬停只改变底色，不做位移；
- 操作按钮固定在行尾；
- 长表格横向滚动。

### 卡片

只在以下情况使用：

- 独立文档/成果；
- 需要状态边框的提示；
- 弹窗与浮层。

普通列表、统计、页面标题不使用卡片包裹。

### 弹窗

- 白面、8—10px 圆角、1px 边框；
- 标题用宋体，正文 14px；
- 主操作在右下，危险操作与关闭分开；
- 背景遮罩中性色，不使用玻璃拟态。

## 9. 交互

- 页面切换保留编辑器内容；编辑器自动保存状态清晰；
- 生成、上传、解析、导出有进度或状态提示；
- 删除有确认；
- 错误提示说明原因与下一步；
- 右侧辅助栏可收起；
- 移动端不强行压缩三栏，改为单列；
- 关键操作位置固定在页头或结果头部，不随滚动漂移。

## 10. 动效

- 140—220ms，只用于导航、展开、保存状态、图谱选中和进度；
- 不使用漂浮、粒子、光效、视差；
- `prefers-reduced-motion` 下关闭。

## 11. 验收

1. 页面主体是真实工作内容；
2. 无大型宣传 Hero 和系统规模卡片墙；
3. 八模块颜色只做识别；
4. 主操作颜色统一；
5. 首页、备课、质检、知识库有不同工作布局；
6. 功能、路由、编辑器、质检、检索、导出正常；
7. 1920 / 1440 / 1024 / 768 / 390 无横向溢出；
8. 控制台 0 新增错误；
9. 测试结果以实际执行记录为准。
