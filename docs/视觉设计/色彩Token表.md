## 二、统一品牌操作色

所有页面的主按钮、核心操作、当前选中和键盘焦点统一使用：

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#4A5F52` | 主要按钮、选中边界 |
| `--brand-ink` | `#34473A` | 链接、悬停 |
| `--brand-strong` | `#3E5245` | 主按钮按下 / 高对比 |
| `--brand-soft` | `#EEF2EE` | 轻选中、提示底 |
| `--brand-line` | `#CAD6CD` | 轻描边 |

白字在 `--brand` 上对比度 **7.0:1** 以上，满足 AA。

## 三、八模块识别色

模块色只用于：导航图标、当前模块细色条、分类标签、模块内少量重点标记、图表区分。

**不再用于页面背景、主按钮、大面积色块或卡片底色。**

| 模块 | Token `--module` | 浅色标识 `--module-soft` | 主要用途 |
|---|---|---|---|
| 教学工作台 | `#C58B35` | `#FFF4DF` | 首页导航、当前项色条 |
| 专业体系数据库 | `#4F7FA8` | `#EAF2F8` | 专业层级、分类标签 |
| 专业知识库 | `#49846D` | `#EAF4EF` | 知识分类、阅读选中 |
| 智能备课中心 | `#D47A57` | `#FFF0E9` | 备课导航、任务标签 |
| 教学质量检测 | `#8068A8` | `#F1ECF8` | 质检导航、问题定位 |
| 知识图谱 | `#3E8B8C` | `#E7F4F3` | 节点、当前案例 |
| 资料管理中心 | `#647C9B` | `#EDF2F7` | 文件类型、资料分类 |
| 教学成果管理 | `#7D8754` | `#F0F2E5` | 成果分类、归档状态 |

使用规则：

1. 页面背景统一 `#F7F6F1` / `#FFFFFF`，不随模块变化；
2. 主按钮统一 `--brand`，不随模块变化；
3. 模块色只出现在小面积识别元素；
4. 颜色不能作为唯一信息，状态必须有文字；
5. 成功 / 警告 / 错误仍使用统一功能色。

## 四、字体与字号

| 层级 | 字号 | 字重 | 行高 |
|---|---:|---:|---:|
| 页面主标题 | 24—30px | 650 | 1.25 |
| 工作区标题 | 16—20px | 650 | 1.35 |

## 五、圆角 / 边框 / 阴影

## 六、间距与布局

- 页面最大宽度：1360—1600px，按模块内容密度决定；
- 页面左右内边距：`clamp(20px, 3vw, 40px)`；
- 工作区列间距：18—22px；
- 列表行高：44—56px；
- 表单字段间距：9—12px；
- 页面区块间距：22—28px；
- 侧栏宽度：260px；顶栏：56px。

## 七、交互状态

| 状态 | 表现 |
|---|---|
| hover | 背景 `--hover`，边框 `--line` |
| focus | 2px `--brand` 外环 |
| active | 主按钮 `--brand-ink` |
| disabled | 40% 透明度，保留文字 |
| selected | 中性纸面 + 2px 模块色左侧条 |
| error | `--danger` 文字 + `--danger-soft` 底 |
| success | `--success` 文字 + `--success-soft` 底 |

所有动效 140—200ms，只用于状态变化；`prefers-reduced-motion` 下关闭。
