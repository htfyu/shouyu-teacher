## 四、使用规则

1. 主色只用于图标、细边框、标题标记、当前导航、重点按钮和图表主序列；
2. 不铺满整页，不用高饱和大色块；
3. 页面底色只使用对应模块的极浅纸面版本；
4. 成功 / 警告 / 错误仍使用统一功能色，不随模块变化；
5. 所有模块共享按钮尺寸、圆角、焦点环和交互状态；
6. 正文不用彩色，彩色只做层级和动作提示；
7. 图表和状态必须同时有文字，不能只靠颜色区分。

## 五、字体

- 正文：Source Han Sans SC / Noto Sans SC / Microsoft YaHei；
- 页面主标题、课程包标题、质量分数：Noto Serif SC / Source Han Serif SC / Songti SC；
- 数字与参数：等宽回退 `Cascadia Code / Consolas`；
- 不使用装饰字体，不加载外部字体文件。
