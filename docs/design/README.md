## 使用规则

1. 先读授渔自己的 `PRODUCT.md` 和 `DESIGN.md`。
2. 外部参考只解决“craft 水平”，不提供页面结构。
3. 任何与教师工作流冲突的参考，一律让位于授渔业务。
4. 不把多个品牌的颜色、字体、卡片、动效拼成一个混合皮肤。
