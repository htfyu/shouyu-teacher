# 授渔 V3.0 · 教师操作流程说明

> 目标：第一次使用的职业院校教师，不读长篇说明，也能从选课走到可审核、可导出的教学成果。  
> 依据：2026-11-17 当前线上版本。

## 一、先记住五个入口

侧栏只保留四个核心入口：

1. **工作台**：今天做什么、上次备到哪。
2. **我的课程**：课程目录 + 课程工作空间（章节、任务、知识、资料、项目）。
3. **备课工作室**：六步备课 + 项目文档工作区。
4. **我的成果**：打开、版本、审核、导出。

专业数据库、质量检测历史、专业知识库、知识图谱、资料中心、模板库、教学应用成效、历史记录、系统设置、使用说明收进 **“更多功能”**。

> “开始备课 / 新建备课”只进入六步备课；“新建对话”只用于临时提问和单份草稿。两者不再混用。

## 二、开始一次备课

### 入口 A：从工作台

1. 点右上角 **新建备课**；
2. 进入第 1 步“选专业课程”；
3. 不会自动带入 PLC 演示课程。

### 入口 B：从我的课程 / 课程工作空间

1. 打开“我的课程”；
2. 进入具体课程工作空间；
3. 在“章节与任务”中选章节或典型任务；
4. 点 **开始备课 / 用本章备课 / 用这个任务备课**；
5. 直接进入第 2—3 步，课程、章节、任务已带入。

### 入口 C：从常用课程

工作台“我的常用课程”中点某门课，打开该课程的课程工作空间；在“章节与任务”中选择任务后开始备课，章节、任务和知识包已带入。

### 入口 D：从专业知识库（更多）

1. 打开“更多功能 → 专业知识库”；
2. 搜索资料并点开右侧正文；
3. 点 **用于备课**；
4. 资料作为参考来源带入；如果资料能对应到课程，会直接定位到该课程第 2 步，否则先选课程。

## 三、六步流程

### 第 1 步：选专业课程

- 先选专业，再选课程；
- 显示专业、专业组、课程类别、知识包情况；
- 占位课程和“暂无公开资料”不会出现在可选课程里；
- 没有选中课程时，“下一步”不可用。

### 第 2 步：定章节任务

- 系统从课程知识包自动带入章节和典型工作任务；
- 直接沿用，或在下拉框中修改；
- 显示本章知识点数量、知识包版本、审核状态；
- 参考材料会显示在这里，可移除。

### 第 3 步：教学配置

- 教学对象、建议学时、教学条件；
- 教学条件可以留空，不强制；
- “补充目标”放在折叠区，需要时再填；
- 点“下一步”自动保存草稿。

### 第 4 步：确认并生成

- 汇总课程、章节、任务、教学对象、学时、条件、参考材料；
- 点 **生成 10 类教学资源**；
- 生成后自动运行一次规则质检。

### 第 5 步：编辑与质检

- 左侧显示本次配置摘要，右侧显示 10 类文档；
- 可编辑文档、重新检测、打开完整审阅工作区；
- 质检分数只代表规则检查，不代表学校审核；
- 点 **下一步：保存与导出**。

### 第 6 步：保存与导出

- 显示保存位置、版本、质检分数、审核状态；
- 可提交审核、导出 DOCX、查看成果、完成；
- 成果保存在本机 IndexedDB；换设备用设置中的完整备份。

## 四、草稿

- 第 2—4 步点 **保存草稿**，或点“下一步”时自动保存；
- 退出后，工作台“继续上次的备课”会显示未完成草稿；
- 备课工作室也会显示草稿提示；
- 刷新页面不会丢失草稿；
- 生成资源后草稿自动清除，成果进入我的成果。

## 五、继续修改旧成果

1. 打开“我的成果”；
2. 找到资源包，点打开；
3. 点“在编辑器中修改”；
4. 修改后自动保存；
5. 系统生成新版本，旧版本进入版本历史；
6. 在“版本”中可查看、恢复旧版本。

## 六、质量检测

- 备课第 5 步会自动质检；
- 从“更多功能 → 质量检测”可独立进入；
- 左栏问题、中栏原文、右栏规则与建议；
- 可应用结构修复、忽略非关键提醒、恢复提醒、重新检测；
- 问题修改后重新质检，分数更新。

## 七、导出

在我的成果或第 6 步中：

- DOCX：标准文档；
- Excel：表格类资源；
- Markdown：可复制文本；
- PDF：浏览器打印。

导出前仍须教师核对设备参数、安全条款和学校标准。

## 八、边界

- 知识包是校本示例，不代表学院正式审核；
- 规则分数不是专家结论；
- 参考材料只作为来源附入，不会自动改写教师内容；
- 对话生成不是完整备课流程；
- 数据保存在本机浏览器，换设备需备份迁移。
