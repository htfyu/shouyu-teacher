# 匠备 V2 · 作品设计方案

## 1. 定位

面向技工院校 / 职业院校教师的工学一体化教学工作平台。目标不是“聊天”，而是把真实教学任务转成**有依据、可编辑、可导出、可审核**的成果，同时明确边界与人工责任。

## 2. 用户与场景

- 专业课教师：备课、任务单、工作页、评价、实训安全、听评课；
- 教研组：统一模板、知识库材料、听评课记录；
- 学校：可替换的校本知识库与安全代理；当前不提供多用户权限。

五类基础场景：教案、任务单 / 工作页、评价表、安全查询、听课评课。

## 3. 核心设计

### 3.1 双引擎

```text
用户条件
  → 参数澄清
  → 本地检索（章节级）
  → 本地完整结构
  → [可选] AI 改写关键模块（流式、需授权、隐私网关）
  → 合并 + 引用校验 + 合规自检
  → 人工审核
  → 编辑 / 导出 / 历史
```

- 本地永远可用；
- AI 只改写关键模块，避免长度上限导致半成品；
- 安全、超范围、隐私和参数澄清由本地边界层处理。

### 3.2 知识库

- 12 个专业包（每个 2 份 × 4 章节）+ 原 9 份材料；
- 元数据：专业、课程、来源、作者、发布时间、版本、更新、范围；
- 本地混合检索：n-gram + 场景权重 + 概念扩展；
- 自定义材料 CRUD、JSON 导入导出、重复检测、版本快照；
- 引用绑定到章节，来源可展开。

### 3.3 资料中心

- 本机解析 TXT / MD / CSV / JSON / DOCX / PDF / XLSX / PPTX；
- 进度、分块、预览、隐私检查、加入知识库；
- 扫描 PDF 可选 OCR；
- 依赖按需加载，避免首屏负担。

### 3.4 数据

- IndexedDB 主存储；localStorage 兼容回退；
- 自动标题、搜索、分类、收藏、改名、批量删除；
- 完整 / 仅对话 JSON 备份与恢复；
- 删除本机数据；
- 不宣传跨设备同步。

### 3.5 隐私与安全

- 规则检测 + 上下文 + 身份证校验位；
- 上传前与 AI 发送前双网关；
- 可自动脱敏后继续，原文不上传；
- 前端无模型 Key；生产安全代理放服务端；
- 输出转义，AI Markdown 结构化解析，不直接注入 HTML。

### 3.6 编辑器与导出

- 分栏实时预览；块级编辑；表格编辑；
- 拖动 / 上下移动；撤销恢复；自动保存；
- DOCX（标题、表格、页码、来源）、XLSX（正文 / 表格 / 来源）、TXT、Markdown；PDF 走浏览器打印另存。

## 4. 视觉

- 黑白线稿、衬线标题 + 等宽标签；
- 硬边框、纸面感、少量阴影；
- 统一按钮 / 表单 / 卡片 / 空状态 / 错误态；
- 移动端隐藏侧栏抽屉、单列布局、表格横向滚动。

## 5. 真实性与边界

- 不伪造国家标准、行业标准、企业数据、设备参数、学生数据；
- 知识库标明校本示例；
- AI 输出标明辅助草稿；失败可回退；
- 未实现的账号、云同步、多用户、独立命题 / PPT / 管理模块明确列出，不放假按钮。

## 6. 技术栈

- 原生 ES Modules + CSS，无框架、无构建；
- IndexedDB、Web Crypto 未用于加密；
- PDF.js / mammoth / SheetJS / JSZip 本地 vendor；
- Tesseract OCR 按需 CDN；
- Cloudflare Worker / Vercel 安全代理（未部署）；
- GitHub Pages 静态部署。

## 7. 验收重点

1. 五场景可生成、可编辑、可导出；
2. 12 专业可检索、引用可回溯；
3. 资料可解析、可预览、可入库；
4. 历史可备份恢复；
5. 隐私网关有效；
6. AI 真实流式、失败回退；
7. 移动端无溢出；
8. 无控制台错误、无 Key 泄漏。
