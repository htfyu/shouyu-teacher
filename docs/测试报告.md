## 三、AI 实测

### 1. AI 体验通道（真实调用，非 Mock）

- 模型：`openai-fast`（公共服务匿名模型）
- 生成：本地完整教案 + AI 改写 4 个关键模块；流式显示，约 60—75 秒完成；`finish_reason=length` 时界面显示“输出达到长度上限”。
- 对话：真实流式回答，约 75 秒；引用 3 处本地知识库来源；输出达到长度上限时追加提示。
- 引用：专业包来源 `PK-EL-01 §02` 等进入来源面板；AI 未引用时会显示“AI 引用检查”警告，不伪造引用。
- 失败回退：配置不可达代理后，界面自动回退本地引擎，保留 16 处本地依据，显示错误和“重试 AI 增强”。
- 稳定性改造：新增 `streamAIWithRetry`，只在尚未收到文本时自动重试一次；收到部分文本后不重试，避免界面重复片段；本次未对公共体验通道做大规模限流/断网自动化测试。

### 2. 线上固定地址实测

- 页面 200；7 个导航；知识库 33 份；vendor / AI / 文件 / 隐私模块均 200；
- 线上本地教案生成、来源面板、DOCX 下载、DOCX 文件解析、移动端无横向溢出、控制台 0 错误；
- 线上「测试连接」返回“体验通道可用（openai-fast）”；
- 线上一轮真实 AI 对话返回 26.4 秒流式内容，来源 3 处。

### 3. 未验证

- 未部署 Cloudflare Worker / Vercel Function；
- 未使用真实 DeepSeek / OpenAI Key 调用安全代理；
- 代理实现有 8 项 Worker Mock 测试（`tests/server.test.mjs`）；Vercel 只做了实现者 Mock，不作为本报告通过项；
- 公共体验通道受第三方限速、长度与可用性影响，不能代表生产 SLA；
- 长回答被上游截断但未返回 `finish_reason` 的情况，已增加“未写完”启发式提示，但尚未做大规模准确率评估。

## 五、安全自查

| 项目 | 结论 |
|---|---|
| 前端模型 Key | 无；前端只有代理地址与可选访问口令 |
| 代理密钥 | 服务端环境变量；Mock 测试不返回 Key |

| 权限 | 无账号系统；不做多用户权限承诺 |
| 依赖 | 本地 vendor，保留许可；依赖版本与来源见 `assets/vendor/README.md` |
| 备份 | JSON 可能含教学内容，界面提示存放于学校批准位置 |
