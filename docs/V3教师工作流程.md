# 授渔 V3.0 · 教师核心工作流程

> 目标：一位第一次使用的教师，不读系统结构说明，也能从“我的课程”走到“可审核、可导出的教学成果”。

## 一、主流程

```mermaid
flowchart LR
  A[工作台] --> B[我的课程]
  B --> C[课程工作空间]
  C --> D[选章节/典型任务]
  D --> E[六步备课]
  E --> F[备课项目]
  F --> G[编辑当前文档]
  F --> H[质量检查]
  H --> G
  G --> I[保存]
  I --> J[提交审核]
  J --> K[导出 DOCX/XLSX/MD/PDF]
  K --> L[我的成果]
```

## 二、从零开始：第一次备课

### 1. 进入课程

- 工作台 → “我的课程”；
- 或顶部“开始备课” → 六步第 1 步；
- 或直接点“我的常用课程”。

课程页面自动带入：

- 专业系 / 专业组 / 专业；
- 课程名称、课程类别；
- 知识包状态、版本；
- 章节、知识点、典型任务；
- 相关教学资源。

**不需要再次选择专业或输入课程名称。**

### 2. 选择教学任务

在“章节与任务”中：

- 浏览章节知识点；
- 点“用本章备课”；
- 或点某个典型任务“用这个任务备课”。

进入六步第 2—3 步，章节和任务已带入。

### 3. 六步备课

| 步骤 | 教师动作 | 系统行为 |
|---|---|---|
| 1 选专业课程 | 选专业、选课程 | 从专业数据库带入课程、知识包 |
| 2 定章节任务 | 确认或调整 | 自动带入第一个章节/任务 |
| 3 教学配置 | 确认对象、学时、条件 | 给默认值；条件可空；自动保存草稿 |
| 4 生成资源 | 点生成 | 生成 10 类文档并自动质检 |
| 5 编辑与质检 | 看文档、处理问题 | 项目三栏、质量面板 |
| 6 保存与导出 | 审核、导出 | 保存项目、版本、导出记录 |

### 4. 在同一个项目里编辑

进入项目后：

- 左栏切换 10 类文档；
- 中栏阅读当前文档；
- 右栏切换质量 / 资料 / 属性 / AI 建议；
- 点“编辑当前文档”打开结构化编辑器；
- 切文档不会丢失内容，因为所有文档在同一个项目 artifact 中。

### 5. 质量检测

- 右栏质量面板显示分数、三层、10 维度和问题；
- 点问题 → 定位到对应文档并高亮；
- 点“在编辑器中修改”处理原文；
- 点“应用结构修复”处理可自动修复问题；
- 点“忽略”隐藏非关键提醒，不改变分数；
- 需要完整审阅时再打开质量检测历史页。

质量检测不再要求离开备课项目。

### 6. 保存与导出

- 编辑自动保存；
- 项目头显示保存时间；
- 提交审核会记录审核状态；
- 每次导出记录类型和时间；
- 我的成果中可打开项目、查看版本、恢复旧版本、再次导出。

## 三、继续旧成果

```text
我的成果 → 打开项目 → 编辑当前文档 → 自动保存
        → 生成新版本 → 版本历史 → 恢复旧版本
```

- 旧项目不需要重新建；
- 课程、章节、任务、质量记录都保留；
- 新版本不会覆盖旧版本，旧版本保留最近 4 个。

## 四、从教学资源带入备课

```text
我的课程 / 更多 → 专业知识库 → 搜索资料 → 阅读
→ 用于备课 → 自动匹配课程（能匹配时）
→ 第 2 步（已带参考材料）→ 生成
```

参考材料会进入项目来源，但不会自动改写文档；教师在项目中决定是否采用。

## 五、从知识图谱 / 专业数据库

- 专业数据库保留完整 6/13/56/75/567/134 条记录，用于核查原始数据；
- 知识图谱保留课程—章节—知识点—任务关系；
- 它们是课程空间的资料视图和低频工具，不是主工作流必经页面。

## 六、上下文机制

```text
shouyu.workspace.context.v1
  courseId    当前课程
  chapterId   当前章节
  taskId      当前任务
  projectId   当前备课项目
  updatedAt   更新时间

shouyu.studio.wizard.v1
  未完成草稿的课程/章节/任务/对象/学时/条件/参考材料/当前步骤
```

- 页面刷新后恢复当前课程和项目；
- 直接进入 `/studio` 时优先打开当前项目；
- 没有项目时显示当前课程的“开始新项目”；
- 没有课程时显示选择课程入口；
- 不再通过临时变量假装共享上下文。

## 七、页面目的与下一步

| 页面 | 目的 | 主操作 | 下一步 |
|---|---|---|---|
| 工作台 | 知道今天做什么 | 继续编辑 / 新建备课 | 课程或项目 |
| 我的课程 | 找到要教的课 | 打开课程 | 章节任务 |
| 课程空间 | 看清课程与项目 | 开始备课 | 六步第 2 步 |
| 备课工作室 | 完成项目 | 编辑当前文档 / 生成 | 质量检查 |
| 质量面板 | 定位并处理问题 | 修改 / 忽略 | 下一步保存 |
| 我的成果 | 归档、版本、导出 | 打开项目 | 继续编辑或导出 |

## 八、失败与空状态

- 没有课程：显示“先选课程”，不预选 PLC；
- 没有项目：显示“开始第一个项目”；
- 没有质检：显示“运行质检”，不显示假分数；
- 没有资料：说明未匹配，可去知识库检索；
- 生成失败：保留输入，提示原因；
- 导出失败：不记录为成功导出。

## 九、真实操作说明

本项目当前未进行真人教师可用性实验。流程和截图来自实际浏览器操作；测试数据来自真实本地生成，不使用伪造的教师反馈。
