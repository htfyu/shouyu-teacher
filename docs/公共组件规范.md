# 公共组件规范（工作型 UI）

> 适用范围：所有一级页面、二级页面、弹窗、编辑器和移动端。  
> 实现基线：`assets/work-theme.css`；未使用的旧组件样式不再作为新页面依据。

## 1. 按钮

| 类型 | 类名 | 背景 | 文字 | 用途 |
|---|---|---|---|---|
| 主操作 | `.btn.btn-solid` | `--brand` `#4A5F52` | `#FFFFFF` | 生成、保存、确认、新建 |
| 次操作 | `.btn` | `#FFFFFF` | `--ink` | 编辑、导出、刷新 |
| 文字 / 辅助 | `.btn-ghost` | 透明 | `--muted` | 返回、取消、更多 |
| 危险 | `.btn` + danger | `--danger-soft` | `--danger` | 删除 |

规则：

- 高度 32—36px，圆角 6px，1px 边框；
- 主操作每屏最多 1—2 个；
- 同一区域不并排两个主按钮；
- 禁用保留文字，仅降低透明度；
- 不改变不同页面的点击行为。

## 2. 输入与选择

- 高度 34px，圆角 6px，边框 `--line-strong`；
- focus：`--brand` 边框 + 2px `--brand-soft` 外环；
- 标签在上、说明在下，不用 placeholder 代替标签；
- 下拉选项使用原生 `<select>`；移动端分类筛选使用原生下拉；
- 必填项在标签后以文字标注，不只靠红色。

## 3. 列表与表格

- 行高 44—56px，底部 1px 分隔线；
- 悬停只改变底色，不位移；
- 行尾操作固定右对齐；
- 标题、元信息、状态三列结构；
- 表格允许横向滚动，不压缩到不可读；
- 手机隐藏非关键元信息，但保留主标题、状态和主操作。

## 4. 卡片

只有以下场景使用卡片：

- 独立文档 / 成果；
- 需要边框表达状态；
- 弹窗、浮层、空态。

禁止：

- 把每个统计数字做成卡片；
- 把普通列表包成卡片墙；
- 所有页面使用同一套卡片网格。

## 5. 页头

### 工作型页头

用于首页、备课、质检、知识库：

```text
面包屑 / 当前上下文
页面标题（课程名或模块名）
状态行：版本、状态、问题数、待确认数
右侧固定操作区
```

- 页面标题 24—30px，宋体；
- 上下文行 12px，次级色；
- 操作区不随滚动漂移；
- 不使用大段产品介绍。

### 传统页头

专业体系、资料中心、成果、图谱、应用成效仍使用 `page-head`，但统计压缩为摘要带，不再使用四张卡片。

## 6. 弹窗

- 白面，8—10px 圆角，1px `--line` 边框；
- 标题宋体 20px，正文 14px；
- 宽版最大 `min(1100px, calc(100vw - 24px))`；
- 底部左：辅助操作；右：取消 / 确认；
- 危险确认与普通确认分开文案；
- 弹窗打开时焦点进入标题或第一个字段。

## 7. 状态与反馈

| 状态 | 表达 |
|---|---|
| 保存中 | 行内“正在保存…”；不阻塞 |
| 已保存 | 行内“已保存 · 时间” |
| 生成中 | 按钮禁用 + 文案“正在生成…” |
| 长任务 | 进度条或阶段文字 |
| 失败 | 明确原因 + 下一步；保留已有内容 |
| 空数据 | 说明为什么为空 + 一个真实操作 |
| 待审核 | 文字标签，不只靠颜色 |
| 已忽略 | 文字“已忽略”，可恢复 |

## 8. 六步流程与草稿

### 步骤条

- 6 个步骤，当前步骤用模块色下边线和实心编号；
- 已完成步骤显示勾，未开始步骤为灰色；
- 手机上横向滚动，不把所有步骤压缩成一行小字；
- 每一步只显示当前步骤内容，不把全部字段堆在一页。

### 步骤操作

- 每步最多一个主操作（下一步 / 生成）；
- 上一步为文本或次按钮；
- 保存草稿固定在页头，不在步骤底部重复；
- 主操作不可用时必须保留可读文字，并说明缺少什么。

### 草稿

- 自动保存 + 手动保存都写入同一草稿键；
- 草稿包含步骤、课程、章节、任务、对象、学时、条件、参考材料；
- 工作台与备课中心显示“继续草稿”；
- 生成后清除草稿；
- 不自动覆盖用户正在填写的新内容。

## 9. 折叠 / 辅助栏

- 备课右侧资料栏：顶部“收起资料/展开资料”；
- 质量检测在 900px 以下自动改为单列，不强制三栏；
- 知识库 700px 以下分类栏收起为下拉；
- 折叠状态只影响布局，不丢失表单内容。

## 10. 图标

- 线性 SVG，1.35—1.5 描边；
- 模块图标使用模块识别色；
- 导航当前项使用 2px 模块色左侧条，不使用整行模块色底；
- 图标不作为唯一信息。

## 11. 文案

- 使用教师语言：“继续上次备课”“还有 2 份待审核”“这份成果还未质检”；
- 不使用“AI 赋能”“魔法生成”“一键智能升级”；
- 技术边界如实写：“知识包待教研组审核”“规则分数不是学校认定”；
- 空态和错误必须给下一步动作。

## 12. 响应式

| 断点 | 行为 |
|---|---|
| >1280 | 完整三栏工作区 |
| 1080—1280 | 备课资料栏下移；质检建议下移 |
| 900—1080 | 首页右栏三列；知识库阅读区缩短 |
| 700—900 | 侧栏抽屉；三栏变单列；知识库列表/阅读单列 |
| <700 | 单列；知识库分类下拉；质检顺序问题→建议→原文；按钮占满可用宽度 |

## 13. 禁止事项

- 用旧蓝色 SaaS Token 覆盖新页面；
- 每个模块一套全页主题色；
- 用无意义统计填满首页；
- 用卡片包裹普通列表；
- 用弹窗替代本可直接阅读的内容；
- 用自动改写覆盖教师内容；
- 用假数据填充空态。
