# 尚未实现功能清单

> 本清单对应当前仓库与线上站点。以下均未用空按钮 / 假页面冒充。需要后端、账号或额外基础设施。

## 〇、专业数据库与课程资源边界

- 学院未公开完整的《专业人才培养方案》《课程标准》《教学计划表》全文，因此没有官方的学时学分、章节表、教材版本和考核比例；页面不编造这些字段；
- 567 条课程记录中，只有 13 条有原表标注的官方课程简介；其余提供的是明确标注的“行业通用参考”备课脚手架，正式授课前须由课程负责人校核；
- 专业组简介、系部教学领域/就业方向汇总，是按成员专业公开信息整理的参考，不是学院单独发布的文件；
- 134 条来源按原表标注“已核验（官方原文）”，本次未逐条重新访问外网复核链接可用性；
- 专业库采用“版本化种子数据 + 本机 IndexedDB 修订”，不支持跨设备同步、多人共享或学校级权限；
- 课程资源编辑、自建专业/课程与隐藏记录只存在当前浏览器，需要迁移时使用导出修订或完整备份。

## 一、账号与协作

- 注册 / 登录 / 找回密码；
- 云端同步与多设备冲突合并；
- 多用户、角色与学校级权限；
- 学校级共享知识库；
- 教学数据分析看板；
- 审计日志、计费、配额。

## 二、独立教学模块

当前为“五个基础场景 + 十类课程资源包”。下列仍未实现为独立表单 / 数据模型：

- 智能命题：选择、判断、填空、简答、实操题、自动组卷、难度分级；
- 真正的 PPT 文件生成 / PPTX 导出（当前只生成“课件内容大纲”）；
- 教研活动总结、教学工作总结模板；
- 课程 / 班级 / 进度 / 教学任务 / 成果归档管理；
- 逐段版本对比（当前只有版本号/时间/质检，可恢复但不能 diff）。

可在 AI 对话中讨论，但没有专用表单、评分模型、数据表和导出。

## 四、文件与服务端能力

- 页眉页脚、图表、公式、批注等复杂 Office 版式完整保留。

## 五、安全与合规

- IndexedDB 加密 / 端到端加密；
- 正式的数据处理协议、等保 / 个人信息保护影响评估；
- 服务端内容审核与学校安全策略；
- 完整 CSP / HSTS 等响应头（GitHub Pages 限制）；
- 生产级密钥轮换与审计；
- 名称 / 地址等弱格式隐私检测的完整召回（当前为规则 + 上下文）；
- 全部个人信息场景的人工复核工作流。

## 六、课程知识包与质量评价边界

- 只完成 4 门代表性课程知识包（PLC技术及应用、工业机器人操作与应用、新能源汽车底盘与维修、网络综合布线）；其余课程记录使用“行业通用参考”骨架，不能算逐门建设完成；
- 课程知识包状态为“待教研组审核”；**在线教研组审核/签字流程未实现**，当前审核记录针对资源包；
- 课程知识包编辑 UI 未开放；章节/知识点/任务修订仍由数据文件维护；
- 知识图谱只覆盖有课程知识包的代表课程，不跨课程推断关系；
- 质量分是规则分，不是学校官方认定；A 结构、B 专业知识、C 教师专家三层分开显示；专业内容仍需课程负责人/教研组复核；
- 教学应用成效模块没有内置真实数据；学校未提供记录时显示“尚未采集”，不得用测试数字冒充试点成果；
- 课程知识包和资源包的“专家认证”只有在知识包 approved 且有教师审核记录时才可能显示，当前均为待审核；
- DOCX 目录是按文档顺序的静态目录，不是 Word 自动页码域；PDF 页码由浏览器打印生成；
- 资源包版本只保留最近 4 个内容版本，不保留所有历史；
- 原表课程来源编号 S20/S27 与其他专业错配，系统保留原值并警示，未擅自修正数据。

## 八、当前替代方案

| 需求 | 当前可用替代 |
|---|---|
| 云端同步 | 导出 / 导入 JSON 备份，手动迁移 |
| 生产 AI 密钥安全 | 部署 `server/` 安全代理；不要在前端填 Key |
| 智能命题等模块 | 使用 AI 对话讨论，人工整理；无结构化表单 |
| 直接 PDF | 浏览器打印 → 另存为 PDF；DOCX/打印有封面、目录、页码 |
| 中文扫描件 | 开启 OCR 后人工校对；默认只处理前几个低文本页 |
| 学校级知识库 | 每个教师本机自定义知识；导出 JSON 共享 |
| 课程知识包扩容 | 按 `curriculum-data.js` 结构逐门建设；无包课程明确标“行业通用参考” |
| 教研组签字 | 当前在成果审核中记录审核人/结论/核对项；知识包签字流程待后端/组织流程 |
| 真实应用成效 | 由教师手动录入或导入真实记录；无数据时显示“尚未采集” |
