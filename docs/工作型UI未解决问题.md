## 一、工程 / CSS

1. **基础层死选择器尚未物理删除**  
   `assets/ui-refresh.css` 仍保留 `.workbench-*`、`.kb-card*`、`.quality-rule-panel`、`.studio-layout` 等不再命中的旧规则。当前不影响渲染，但增加维护成本。物理删除需要逐块回归，本轮未做。

2. **尚未拆分为独立组件 CSS**  
   目前是 `styles.css → ui-refresh.css → work-theme.css` 三层。理想结构是 `tokens.css`、`components.css`、`pages.css`，但需要处理旧页面和打印/编辑器样式，风险较高。

3. **没有截图 diff 自动回归**  
   视觉验收使用实际截图和计算样式，没有接入 Playwright screenshot snapshot / Chromatic 类服务。

## 二、交互

4. **质量检测没有历史检测记录**  
   当前只保留当前 `bundle.quality` 和权重；没有“每次检测的时间线快照”。重新检测会覆盖当前报告。

5. **忽略提醒是本地行为**  
   忽略列表存 `localStorage`，不跨设备，不是学校级审核意见；刷新保留，换浏览器丢失。

6. **质量建议不能自动改写全文**  
   “应用结构修复”只调用既有安全结构修复；专业内容、设备参数、安全条款只能打开编辑器人工修改，不做自动改写。

7. **右侧资料栏只做收起/展开**  
   没有记住用户上次的折叠状态；切页后恢复默认展开。

8. **未保存修改提示依赖现有编辑器逻辑**  
   编辑器自动保存和离开提醒沿用旧实现，本轮没有重写；没有做跨路由的统一 beforeunload 提示。

## 三、响应式 / 可访问性

9. **未做真机测试**  
   1920 / 1440 / 1024 / 768 / 390 为 Edge headless 视口；未验证 iOS Safari、Android Chrome 的虚拟键盘和触摸手势。

10. **知识图谱手机端没有缩放/平移控件**  
    小屏仍需横向查看，未做双指缩放。

11. **颜色对比度未做自动化扫描**  
    正文、次级文字和按钮按 WCAG 公式人工计算；没有 axe-core 全页面扫描。

12. **焦点顺序只做基础检查**  
    键盘 Tab 可操作，但复杂三栏页面未做完整焦点陷阱/跳转测试。
