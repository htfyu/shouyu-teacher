# 授渔 V2 · 现场演示脚本（约 4 分钟）

> 建议使用有线网络 / 校园网，提前在设置中确认本地模式或 AI 体验通道。演示前刷新一次，避免旧缓存。

## 0. 一句话

“授渔不是万能聊天框，而是一个有边界、有知识库、能交付可编辑教学成果的教师工作台；本地引擎保底，AI 增强可选。”

## 1. 边界（25 秒）

1. 首页输入：“帮我预测哪个学生考不上。”
2. 展示：明确拒绝、不给标签、不返回无关知识库片段。
3. 再问：“学生上课总睡觉怎么管？” → 说明学生管理不在知识范围，建议班主任 / 学生工作部门。

## 2. 知识库与依据（35 秒）

1. 进入知识库：展示 **35 份材料 / 155 个片段 / 13 个专业包**。
2. 搜索“互锁” → 展示命中章节。
3. 搜索“数控对刀” → 打开专业包，展示来源、课程、适用范围。
4. 打开一份材料，展示：来源、作者、版本、适用范围、章节引用格式。

## 3. 本地闭环（60 秒）

1. 首页“生成教案” → 载入示例 → 生成。
2. 展示：9 个模块、引用来源、合规自检。
3. 点“编辑成果”：改标题、改一段正文，展示右侧实时预览与自动保存；拖动模块排序；撤销 / 恢复。
4. 关闭编辑器，展示“导出 DOCX / Excel / TXT / Markdown”；DOCX 含页码。
5. 打开历史：改名、分类、收藏、批量选择；进入设置展示 IndexedDB 备份 / 恢复。

## 4. 资料中心（45 秒）

1. 进入资料中心，拖入一份 DOCX 或 PDF。
2. 展示解析进度、预览、片段数。
3. 展示隐私流程（若准备含手机号的测试文件：出现掩码确认；否则说明）。
4. “加入知识库” → 回知识库搜索，展示新材料的来源与分块。

## 5. AI 增强（70 秒，需网络）

1. 设置 → 切换 AI 增强 → 阅读并同意数据传输说明。
2. 回到教案，生成。
3. 展示：AI 流式输出、已接收字数、停止按钮；约 60—90 秒后，展示 4 个“AI 改写”模块 + 本地完整结构。
4. 点“AI 原文”展示透明性；右侧提示“AI 生成内容需人工审核”。
5. 若网络失败：展示自动回退本地 + “重试 AI 增强”。

## 6. 收尾（20 秒）

- 本地模式：数据不出浏览器。
- AI 模式：第三方 / 安全代理，发送前隐私检查，失败回退。
- 生产部署：`server/` 安全代理，Key 只在服务端。
- 明确未实现：账号 / 云同步 / 多用户权限 / 独立命题与管理模块。

## 现场避坑

- 公共 AI 体验通道有 30 秒左右限流，演示前不要连续多次调用；失败就展示回退，不要现场等待过久。
- 不要输入真实学生姓名 / 学号 / 手机号。
- 演示“PDF”时说明是浏览器打印另存，不是服务端生成。
- DOCX / XLSX 首次导出会加载本地 JSZip / SheetJS（约数百 KB），稍等即可。
