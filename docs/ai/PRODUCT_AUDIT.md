# 产品与体验诊断

> 依据：当前代码、真实页面渲染、已有测试、产品文档。  
> 不把历史方案当现状；不把未实现能力写成已完成。

## P0 · 阻碍核心业务

无。当前备课、保存、质检、审核、导出链路可运行；不虚构 P0。

## P1 · 严重降低操作效率

### 1. “更多功能”平铺过多，工作阶段不清楚

- 位置：`js/app.js` `renderSidebar`，10 个入口平铺。
- 影响：教师需要在一串工具中判断“资料、质量、记录、设置”的归属。
- 处理：已按 **教学资料 / 审阅与记录 / 设置与帮助** 分组；保留四个核心入口。
- 状态：已实施，待回归。

### 2. “课堂授课”没有真实落点

- 位置：课程工作空间只有概览、章节任务、知识、资料、项目、成果。
- 影响：备课成果无法回到真实授课记录；教学应用成效模块只有手工记录，与课程上下文断开。
- 方案：在课程工作空间增加“授课记录”标签，教师录入日期、班级别名、任务、资源版本、课堂事实/反思；不预置数据。
- 状态：**已实施**（`js/teaching-store.js`；新增/编辑/删除/空状态/汇总/备份恢复；单元测试 5 项；E2E 空状态检查）。仍未实现班级学生名单、排课、考勤和成绩。

### 3. 质量审阅页在 1440 下仍是高密度三栏

- 位置：`renderQualityPage`，问题清单 / 文档 / 问题详情。
- 影响：小字、窄栏、长文档同时出现；教师长时间阅读疲劳。
- 已做：正文 13px/1.8，问题元信息 10.5–12px，右侧问题详情加宽。
- 剩余：三栏在小屏的折叠顺序、问题列表的键盘操作、选中态更明确。

### 4. 旧 AI 对话与主工作流竞争

- 位置：“更多功能”中的“AI 教学对话”，旧 `#/chat/:id` 路由仍保留。
- 影响：产品定位是教学工作平台，不是聊天机器人；入口需要降级但不能删除。
- 处理：已改名为“AI 教学对话”，放在更多功能末尾；不在核心导航。
- 状态：已实施，待观察。

## P2 · 影响视觉或交互体验

### 5. 装饰性 kicker 抢占标题

- 位置：`.page-kicker`、`.programs-kicker` 出现在多数页面标题上方。
- 处理：已隐藏；标题和页面说明承担定位。保留有意义的面包屑。
- 状态：已实施。

### 6. 左侧色条过多

- 位置：导航 active、课程行、专业卡、质量选中行、项目问题、文档目录选中。
- 影响：视觉噪音；不符合新世界“完整边界 + 状态章”的规则。
- 处理：移除导航和内容区左侧色条，改用背景/完整边框/状态章。
- 状态：已实施大部分，待全站扫尾。

### 7. 状态章只是文字，缺少统一语义

- 位置：课程行、专业卡、质量严重度。
- 处理：状态章统一 3px 小圆角、细边框、文字；待审核黄、通过绿、必须修改朱砂、中性灰。
- 状态：已实施课程行与质量行；专业卡待逐项核对。

### 8. 课程工作空间空状态占据大面积但缺少下一步

- 位置：`renderCourseWorkspacePage` 概览。
- 影响：没有项目时，右栏空白，教师不知道先做什么。
- 方案：给出“从本章节开始备课 / 查看知识依据 / 导入资料”三个真实动作，并把状态章放在课程标题旁。
- 状态：待实施。

## P3 · 细节优化

- 顶栏中心提示语在部分页面重复页面副标题，可改为当前工作区状态。
- “专业数据库”导航名与页面标题“专业与课程”不完全一致，考虑统一为“专业体系”或“专业与课程”。
- 旧 CSS 五层叠加，存在未使用规则；本轮不物理删除，避免影响未覆盖页面。
- `js/app.js` 单文件过大；本轮不做框架迁移，只做低风险局部抽取。
- 历史记录页仍使用旧式“使用统计”文案，与“工作手册”世界不完全一致。

P1 导航分组（已做） → 课堂记录（待做）

- 不重写 `app.js` 或替换技术栈。
- 不改 IndexedDB/localStorage 既有键和导出格式。
