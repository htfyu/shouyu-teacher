# 决策记录

## 2026-11-19 · 产品边界

用户确认：

1. **允许新增全部当前缺失模块**；但数据仍必须本地、真实、可追溯，不能预置伪造数据。
2. **完全重新建立视觉世界**；旧视觉只作为功能证据与反例，不保留其配色/版式权威。
3. **数据层保持现状**：静态前端 + 浏览器存储；不改数据库、API、导出格式和已有数据结构。

推论：

- 先重构导航、页面职责和核心工作流，再逐模块补真实功能。
- 课堂/授课相关能力应放在“课程工作空间”的上下文中，而不是再加一个孤立一级菜单。
- 新增记录只能由教师真实录入；没有数据时用空状态，不生成样品。

## 2026-11-19 · 视觉方向

- Impeccable `concept-seed` 指定构建第 7 个 grounded direction；本轮定义为 **Workshop Folio / 工作手册**。
- 由于用户明确要求“完全重新建立视觉世界”并授权自主执行，本轮直接落地 assigned direction，没有额外阻塞在视觉二选一决策页；该方向仍可回滚/重做，不属于永久品牌锁定。
- 视觉世界只提供：字体、颜色、密度、一个签名动作。
- 签名动作：**状态章（status stamp）** + 真实编号；不做无意义装饰。
- 外部参考只作为 craft bar，不直接拼贴 Linear/Notion/Stripe/Apple/Raycast/Framer。
- 旧世界中被否决的做法：暖灰单色后台、装饰性英文 kicker、左侧色条、所有区块卡片化、8–9px 关键信息。

## 2026-11-19 · 导航

保留四个核心入口，不增加一级菜单数量：

```text
工作台 / 我的课程 / 备课工作室 / 我的成果
```

“更多功能”按工作阶段分组：

```text
教学资料 / 审阅与记录 / 设置与帮助
```

原因：教师的主路径是“选课 → 备课 → 审阅 → 归档”；专业库、知识库、资料、模板是支撑资料，不应与四个主任务平权。

## 2026-11-19 · 课堂模块

计划将“课堂授课”放在课程工作空间，而不是独立一级页面：

- 课程已有章节、任务、备课项目和成果，课堂记录天然属于该课程上下文。
- 课堂记录只保存教师真实录入的课堂事实、日期、班级别名、资源版本、观察/反思，不保存学生个人信息。
- 没有真实记录时显示空状态，不生成演示课堂数据。
