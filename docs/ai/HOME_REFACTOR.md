## 1. 问题

原首页用文字承担了本应由结构承担的工作：

- 问候语与工作区状态说明；
- “还没有进行中的备课”“还没有教学成果”“还没有上传文件”等多个空状态；
- 每门课程重复一次“待教研组审核”；
- 单项工具前的“对话生成，不是完整备课”标签和说明段落；
- 右栏为 0 的统计行、“尚未采集”和提醒段落。

这些内容让页面读起来像一份使用说明，而不是工作区。


## 4. UX

- 首屏只保留“工作台”标题和一个主 CTA“新建备课”。
- 空状态不再成段解释；没有内容就不渲染对应 section。
- 课程审核状态合并为分组标题，行内只保留课程、专业、章节、知识点。
- 单项工具使用原生折叠区；需要时展开，不占据首屏。
- 右栏只显示非零统计；无数据时不出现 0 值行。
- 有项目时“继续上次的备课”出现；同一项目不会同时出现在“最近成果”中。

## 5. DX

- 删除首页未使用的 `stats`、`featured`、`approvedPacks`。
- 课程状态先按真实 `statusLabel` 分组，再统一渲染，避免重复字符串。
- 待处理项先过滤 `value > 0`，再统一渲染。
- 首页空态/有数据态由同一模板分支控制，不再维护三套空状态。
- 移除首页嵌套 `<main>`，只保留应用层一个 `<main>`。
- 清理旧首页死样式约 6.7KB；CSS 计算样式指纹仍为 32 组合 0 差异。
- E2E 新增 6 项结构断言和 2 项键盘断言，当前 **88 passed**。

## 6. AX

- 稳定语义：`h1 工作台`，section 使用 `h2`，课程状态组使用 `h3`。
- 稳定属性：`data-home-state="empty|active"`、`data-role="home-continue|home-recent|home-courses|home-tools|home-todo|home-side"`。
- 原生 `<details>/<summary>`，键盘 Enter 可展开/收起，无需自定义 JS。
- 右栏空态使用 `role="status"`，不依赖颜色。
- 移除重复状态和空提示，降低读屏与智能体解析噪声。
- 页面只有一个 `<main>`，一个主 CTA。
