# 授渔 V2.2 · 工作型 UI 审计报告

> 审计日期：2026-11-17  
> 审计范围：`index.html`、`assets/styles.css`、`assets/ui-refresh.css`、`assets/work-theme.css`、`js/app.js` 的页面渲染与交互。  
> 目标：识别展示型 UI、重复覆盖、旧主题残留和页面结构问题，再实施工作型重构。

## 二、审计发现

### A. 展示型结构

1. 首页有大型 Hero、宣传标题、四张系统统计卡、产品功能卡片墙和聊天输入区。
2. 专业体系、知识库、资料中心、成果中心重复使用“标题 + 简介 + 四张统计卡 + 卡片网格”。
3. 统计数字（567 课程、147 片段等）在首页占据主视觉，但不直接支持当天工作。
4. 备课中心把知识准备与质检面板堆在结果上方，真正的文档预览被推低。
5. 质量检测是“报告卡片列表”，没有形成问题—原文—建议的审阅关系。
6. 知识库是彩色卡片网格，阅读正文需要另开弹窗。

### B. 视觉系统

1. 八个模块各自改变整页底色和按钮颜色，形成八套主题，削弱统一操作认知。
2. 大量非对称圆角、纸面渐变、点阵纹理、环形装饰和细线。
3. 统计卡、知识卡、成果卡使用相似的卡片语法。
4. 旧蓝色 SaaS Token 与上一版暖色主题同时存在，存在覆盖链复杂的问题。
5. 辅助文字大量使用 8—10px，长时间阅读疲劳。

### C. 结构 / 交互

1. 质量检测无法从问题直接定位原文，也不能在页面内连续处理。
2. 知识库列表与阅读分离，检索后需要二次打开弹窗。
3. 备课中心没有稳定的“上下文—配置—编辑—资料”三栏工作区。
4. 首页没有“继续上次备课”的最高优先级入口。
5. 侧栏“本地工作区”统计块在 1000px 高度下被底部栏裁切。
6. 移动端知识库分类占用过多首屏高度。

## 三、已实施改造

### 1. 基础视觉

- 页面背景统一 `#F7F6F1`，内容面板 `#FFFFFF`；
- 正文 `#30332F`，次级 `#71736F`；
- 页面不再随模块改变底色；
- 统一品牌操作色 `#4A5F52`，主按钮不再随模块变色；
- 八模块颜色仅用于导航图标、当前项色条、分类标签和少量状态；
- 删除纸张纹理、环形装饰、渐变 Hero；
- 圆角统一 4 / 6 / 8 / 10px，阴影只保留必要层级；
- 辅助工作文字最低 12px。

### 2. 页面结构

| 页面 | 新结构 |
|---|---|
| 首页 | 日期问候 + 新建备课 / 继续上次 / 最近编辑 / 常用课程 / 今日待处理 / 最近文件 |
| 智能备课 | 上下文页头 + 左配置 + 中文档 + 右知识资料（可收起） |
| 质量检测 | 左问题清单 + 中原文 + 右建议与人工审核 |
| 专业知识库 | 左分类 + 中列表 + 右阅读 |
| 专业体系 | 保留目录 + 内容，统计压缩为索引带 |
| 知识图谱 | 保留节点/连线画布，去掉装饰主题 |
| 资料中心 | 上传 + 文件列表 + 解析状态 |
| 成果管理 | 档案列表 + 版本 / 审核 / 导出 |

### 3. 交互

- 首页“继续编辑”直接打开编辑器；
- 备课右侧资料可收起/展开；
- 质量检测支持问题选择、上一条/下一条、定位原文、应用结构修复、忽略提醒、恢复忽略、重新检测；
- 知识库列表选择后右栏直接阅读；
- 移动端知识库分类改为下拉选择；
- 移动端备课生成后自动滚动到文档区。

## 五、仍存在的旧样式

以下旧选择器已不对应新页面 DOM，但仍在基础层中保留：

- `.workbench-hero`、`.workbench-grid`、`.workbench-card*`；
- `.kb-card*`、`.kb-grid`；
- `.quality-rule-panel`、`.quality-report-list`；
- `.studio-layout`、`.studio-readiness` 的部分旧子规则。

保留原因：

- 与 `styles.css` 的响应式块和少量二级组件共用选择器；
- 当前没有构建步骤，直接删除需要逐块回归，避免误伤编辑器和弹窗；
- 新页面不再生成这些类，视觉和布局不受影响。

处理计划见 [CSS清理记录.md](CSS清理记录.md)。

## 六、未改动的业务部分

- 路由结构与 hash 解析；
- 专业数据库结构与 567 条课程记录；
- AI 调用、隐私检查与回退；
- 知识库检索、自定义材料与导入导出；
- 质量检测规则、权重和评分封顶；
- IndexedDB / localStorage 存储；
- 文件解析、编辑器、自动保存、版本、DOCX/XLSX/PDF 导出；
- 教学应用成效与备份恢复。

**结论：** 展示型结构已从四个核心页面移除，视觉系统收敛为一套中性工作界面；功能逻辑未改，旧样式清理已完成主题层和死页面结构部分，基础层死选择器列入后续清理。
