# 已修复问题清单

## V2 改造中发现并修复

1. **AI 截断被当成完整成果**：匿名体验模型有输出长度上限，`finish_reason=length` 时原逻辑仍把半篇内容当完整结果。现在界面提示截断、日志记录 finish reason，并保留未覆盖的本地模块。
2. **AI 全文替换导致半成品**：原设想是整篇 AI 替换；现在改为“本地完整底稿 + AI 改写关键模块 + 合并”，不会因 AI 只输出 3 节而丢掉其余章节。
3. **AI 引用可伪造**：原解析只接受部分格式，且可能把未在上下文中的已知章节当依据。现在只接受本次提供的来源；未知引用丢弃并提示。
4. **专业包来源无法引用**：原引用解析只支持 `KB-xx`，新增的 `PK-xx` 来源无法显示 / 点击。现在 DOCX / 知识库 / 来源面板统一支持任意文档编号与章节号。
5. **专业知识包未进入备课生成**：原生成只用 9 份旧材料，新增 12 专业包只影响知识库页。现在按专业 / 课程 / 任务检索专业包，接入教案上下文与 AI 来源。
6. **AI 推流长时间显示“正在连接”**：体验模型先输出 reasoning；现在收到响应即更新“已连接，等待模型输出”，并显示进度。
7. **AI 输出未引用无提示**：现在显示“AI 引用检查”警告，不把本地来源冒充为 AI 引用。
8. **编辑器撤销按钮不可用**：输入后按钮未刷新状态；现在输入即更新撤销 / 恢复可用性。
9. **移动端编辑器标题被操作按钮/Toast 遮挡**：移动端改为上下布局，Toast 移到下方。
10. **文件预览出现 `[object Object]`**：PPTX / XLSX 的 pages/sheets/slides 可能是数组；现在统一取数量。
11. **资料名称无法被检索**：文件名 / 来源未进入检索 haystack；现在纳入 source / author / course / specialty / tags。
12. **代理访问口令被写入 IndexedDB**：现在只保存在 sessionStorage，不进入备份与持久设置。
13. **知识库批量导入未做隐私检查**：现在导入前扫描标题 / 来源 / 作者 / 摘要 / 正文，含疑似个人信息则跳过并报告。
14. **自定义知识搜索不到**：已随文件名 / 来源修复；同时支持分类与自定义 ID。
15. **历史记录仍宣称 localStorage**：界面、设置、指南、README 已改为 IndexedDB + 兼容回退。
16. **历史缺少改名 / 分类 / 批量删除**：已增加分类筛选、改名与分类编辑、勾选、全选、批量删除。
17. **文件大小上限不可配置**：设置页新增 1—100MB 配置，保存到 IndexedDB。
18. **DOCX 是 HTML `.doc` 伪格式**：已改为真正 OOXML `.docx`（python-docx 可打开，含表格、页码页脚）。
19. **表格类成果无法导出 XLSX**：新增 XLSX，正文 / 表格 / 引用来源分表。
20. **模板简案 / 教练式评课只是换标题**：已实现结构差异（简案 7 节、教练式 / 教研 5 节）。
21. **超范围问题仍返回知识库片段**：补充学生管理、成绩、命题、排课、PPT、设备操作等边界规则。
22. **安全知识与其他专业包表述冲突**：明确“其他专业包只有教学安全提示，操作级仍仅电工/PLC”，避免把一般提示冒充规程。
23. **文件 OCR 后原文件不可用**：当前会话保留原始 File 句柄；刷新后需重新上传，界面明确提示（仍未做持久化原文件，见未实现清单）。
24. **删除资料后知识库残留**：删除资料时同步删除对应自定义知识文档。
25. **AI 体验通道密钥误解**：界面明确“无密钥公开服务”与“自建安全代理”区别；前端没有模型 Key 字段。
26. **文件上传 / AI 发送隐私提示不完整**：增加发送前隐私网关、自动脱敏、人工确认与撤销授权。
27. **UTF-8 BOM 文件被吞掉第一个汉字**：`TextDecoder` 默认已去 BOM，解析器又 `slice(1)` 一次；已改为 `ignoreBOM` 后只去一个 BOM，并加入回归用例。该 bug 曾导致“学生张伟”变成“生张伟”，同时姓名隐私检测失效。
28. **上游截断但无 finish_reason**：线上实测 AI 回答在句中被截断，界面未提示。已增加“长文本未以终止标点结束”的启发式提示，并标记 `truncated`；该启发式不是精确判定，可能对列表结尾产生少量误报。
