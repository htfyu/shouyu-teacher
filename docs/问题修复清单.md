# 授渔 V2.2 · 操作体验问题修复清单

> 日期：2026-11-17  
> 范围：核心操作入口、导航、六步备课、草稿、成果版本、资源引用、响应式。  
> 验证方式：浏览器实际点击 + 计算样式 + 自动化测试；未编造真人测试。

## 一、入口与导航

| 问题 | 修复 | 验证 |
|---|---|---|
| 侧栏“新建备课”进入根路由/旧对话 | 改为“开始备课”，统一进入六步第 1 步 | 点击 `.new-chat` 后 URL `#/studio`，显示“选专业课程” |
| 顶部“新建备课”创建对话 | 改为“新建对话”，明确只用于 AI 对话 | 顶部按钮文案与行为一致 |
| 首页“新建备课”和侧栏行为不同 | 全部调用 `beginStudioFlow()` | 两个入口都进入第 1 步 |
| 新建默认带入 PLC | 新建时不设置课程，第 1 步必须选专业和课程 | 第 1 步无 `.studio-picked-course`；PLC 只在用户选择后出现 |
| 导航 13 项过载 | 核心 5 项 + “更多功能”折叠 8 项 | 核心导航计算为 5 项；更多可展开 |
| 质量检测入口消失风险 | 保留“更多 → 质量检测”，同时嵌入第 5 步和成果 | 质量页路由与第 5 步入口均可进入 |
| 课程详情“用于备课”进入旧表单 | 改为带入课程进入第 2 步 | 专业库 → 课程 → 开始备课，页面标题为课程名，当前步骤 2 |
| 常用课程直接落到旧 PLC 配置 | 带入课程/章节/任务，进入第 3 步 | 常用课程点击后第 3 步课程名正确 |
| 教学资源只能看不能用 | 右栏新增“用于备课”，材料作为来源带入流程 | 搜索物料分拣资料 → 用于备课 → 参考材料卡片可见 |
| 新建对话空白无引导 | 增加空态：正式备课/快速教案/查资源 | 空对话显示 `.chat-empty`，无空白大页 |

## 二、六步备课

| 问题 | 修复 | 验证 |
|---|---|---|
| 一次展示所有字段，像大型表单 | 拆成 6 步，每步只显示当前内容 | 第 1—4 步各自只显示本步字段 |
| 没有当前步骤状态 | 六步横向步骤条，已完成/当前/未开始 | 当前步骤高亮，完成步骤显示勾 |
| 不能返回上一步 | 第 2—4 步提供“上一步” | 返回后已选课程/章节/输入值保留 |
| 不能保存草稿 | 头部“保存草稿” + 下一步自动保存 | localStorage 有 `shouyu.studio.wizard.v1` |
| 刷新丢草稿 | 工作台和备课中心显示“继续草稿” | 刷新后草稿仍在，恢复后步骤/对象/学时正确 |
| 次要配置占空间 | 补充目标折叠 | 默认收起，展开后可填写 |
| 缺资料无提示 | 占位课程被过滤；无可用课程显示提示 | 第 1 步不出现“暂无公开资料”课程 |
| 章节/任务需要重复选 | 知识包自动带入第一个章节/任务 | 第 2 步已有默认值，可修改 |
| 生成后无法知道下一步 | 第 5 步质量条 + “下一步：保存与导出” | 生成后当前步骤 5，按钮可用 |
| 保存/导出无状态 | 第 6 步显示本机保存位置、版本、质检、审核 | 第 6 步完成面板可见 |
| 生成后左侧仍是完整表单 | 改为本次教学配置摘要，防误改 | 第 5/6 步左侧为摘要和“修改配置” |

## 三、成果与质量

| 问题 | 修复 | 验证 |
|---|---|---|
| 旧成果编辑后没有新版本 | 编辑器保存时写入 bundle 并递增版本 | 编辑标题后 v1 → v2，版本历史 2 条 |
| 成果打开与编辑入口分散 | 成果卡片打开、顶部编辑、首页继续编辑 | 三个入口均进入同一编辑器 |
| 质量检测与备课割裂 | 第 5 步显示分数/问题数，可打开完整审阅 | 第 5 步可进入质量页 |
| 质量页问题/原文/建议分离 | 三栏审阅，问题定位原文 | 问题选择、建议、文档标签联动 |
| 参考材料不能进入成果来源 | `buildTeachingBundle` 接收 `referenceDocs` 并写入 sources | 第 2 步参考卡片与资源包来源存在 |

## 四、样式与响应式

| 问题 | 修复 | 验证 |
|---|---|---|
| 不确定 work-theme 是否加载 | `index.html` 在 `ui-refresh.css` 后加载 `work-theme.css` | 实际样式表 3 个；计算 `--brand-line` 为 `#cad6cd` |
| 首页布局未生效 | `.work-home-layout` 计算为两列 | 1440 下 `777.625px 286px` |
| 备课布局未生效 | `.studio-workspace` 默认两列，辅助栏隐藏 | 1440 下 `300px 775.625px`；展开后三栏 |
| 质量布局未生效 | `.quality-workspace` 计算为三栏 | 1440 下 `286px 505.625px 300px` |
| 资源布局未生效 | `.kb-workspace` 计算为两列 | 1440 下 `190px 885.625px` |
| 手机溢出 | 单列、下拉分类、按钮换行 | 1920/1440/1024/768/390 无横向溢出 |

## 五、未在本轮修复

- 第 1 步专业下拉是 56 项原生选择，没有拼音搜索；
- 草稿恢复需要用户点一次“继续草稿”，不自动打开；
- 质量检测没有历史快照；
- 未做真人教师可用性测试，只做自动化走查和启发式检查；
- 基础层死 CSS 未物理删除。
