# 授渔 V3.0 · 使用说明

## 1. 打开与模式

访问 <https://htfyu.github.io/shouyu-teacher/>。

顶部右侧显示当前引擎：

- **本地模式**：所有生成在本机完成，不联网；
- **AI 增强**：需要先同意数据传输说明；真实模型流式输出；发送前做隐私检查；失败自动回退本地。

切换模式：点顶部模式按钮，或进入「AI 与数据设置」。

## 2. 五个基础场景

1. **生成教案**：专业、课程、工作任务、课型、学时、学情 → 完整教学设计（标准 / 任务驱动简案 / 公开课展示）。
2. **任务单 / 工作页**：生成学习任务单 + 六步工作页。
3. **生成评价表**：过程性 / 课堂观察 / 成果评价，权重合计 100 分。
4. **查实训安全**：仅对电工 / PLC 提供操作级知识库依据；其他场所明确说明边界。
5. **听课评课**：粘贴已脱敏听课记录，生成证据型 / 教练式 / 教研记录。

结果页：

- 左侧正文，右侧依据与合规自检；
- 每个模块可单独复制；
- 可“编辑成果”分栏修改、拖动排序、撤销恢复；
- 可导出 DOCX / XLSX / TXT / Markdown，PDF 用浏览器打印另存；
- “调整参数”可保留其他条件重新生成。

## 3. AI 增强

### 体验通道

- 不需要 Key；
- 数据会发给第三方公开推理服务；
- 限速、输出长度有限；对敏感资料请勿使用；
- 输出被截断时会提示，不会静默伪装完整。

### 自建安全代理

在「AI 与数据设置」选择“学校 / 自建安全代理”，填写部署后的 `/api/chat` 地址。模型 Key 在服务端，不在浏览器。部署见 `docs/AI接入与部署.md`。

### AI 生成如何工作

1. 本地引擎先生成完整结构，保证不会因 AI 截断丢模块；
2. AI 只改写关键模块（教案：目标 / 流程 / 评价 / 安全等）；
3. 合并回本地成果，标注“AI 改写”；
4. AI 失败 / 断网 / 隐私未确认 → 自动回退本地，保留“重试 AI 增强”入口。

## 4. 知识库

- 13 个专业包 + 原 9 份校本材料；
- 支持分类筛选、关键词 + 概念扩展检索；
- 引用细化到 `KB-xx §nn` / `PK-xx §nn`；
- 教师可新增 / 编辑 / 删除自定义材料，导入 / 导出 JSON；
- 内置材料只读，可复制为自定义；
- 详情见 `docs/知识库管理说明.md`。

## 5. 专业数据库与课程资源

1. 左侧进入「专业数据库」；
2. 桌面端在左侧树按“专业系 → 专业组 → 专业 → 课程”逐级点击；手机端用三个级联选择框；
3. 顶部搜索支持专业、培养目标、核心能力、就业方向、课程名、课程类别和简介；
4. 专业页可按课程类别筛选；课程详情有 10 个模块、来源链接和“用于备课”；
5. 原表官方简介标注“原表官方”；其余标注“待完善”或“行业通用参考”，后者不是学院官方文件；
6. 教师可编辑课程资料，保存到本机 IndexedDB；刷新后仍在；
7. “管理数据”可新增专业系 / 组 / 专业 / 课程，编辑、隐藏、恢复，导入 / 导出修订；
8. 专业库修订也会进入完整备份；删除本机全部数据会一并清空；
9. 数据表可从页面“原始表”下载；数据口径见 `docs/专业数据库导入说明.md`。

> 当前只有原表明确给出的 13 条课程官方简介；其余 554 条为待完善/行业通用参考。学院未公开完整教学计划、学时学分与教材版本，页面不编造。
>
> 原表前 12 行课程来源编号为 S1/S20/S27，但 S20/S27 在来源表中属于其他专业；课程详情会显示警示，系统不擅自改写原表，也不把这两个编号当作代表知识包依据。

## 6. 智能备课、质量检测、成果与演示

### 智能备课中心（`#/studio`）

1. 依次选择教学单位 → 专业组 → 专业 → 课程；
2. 选择章节和典型工作任务；当前有 4 门标杆课程（PLC技术及应用、工业机器人操作与应用、新能源汽车底盘与维修、网络综合布线），每门 4 章/15—16 知识点/4—5 任务；
3. 填写教学对象、建议学时、教学条件、教师补充目标；
4. 点击“生成 10 类教学资源”；
5. 在结果页切换 10 个文档标签，查看共享的课程/任务/学时/来源；
6. 可“在编辑器中修改”、重新质检、一键修复结构问题、下载报告、导出 DOCX/XLSX/Markdown/PDF；
7. 可提交教师审核，填写审核人和意见。

知识包状态为“待教研组审核”时，综合质检分最高 84；行业通用参考最高 72。即使教师完成审核，知识包未审核时仍不会显示“专家已认证”。设备参数、I/O 地址、安全条款必须人工核对。

### 质量检测中心（`#/quality`）

- 查看所有已保存资源的质检报告、平均分、待审核数；报告按“问题多/分数低”优先排序；
- A 结构规则、B 专业知识、C 教师专家三层得分/状态；
- 10 维得分、问题等级、位置、建议、依据；待核对知识点/设备/参数清单；
- “权重设置”可调整 10 维权重（归一化计算），保存后重算；
- “完整报告”查看全部问题；“报告”下载 Markdown。

### 成果管理中心（`#/portfolio`）

- 打开、审核、导出、删除资源包；
- 查看版本号、质检分、审核状态、历史版本；
- 历史版本可恢复，恢复后生成新的当前版本；
- 完整备份包含成果库和应用成效记录。

### 教学应用成效（`#/impact`）

- 只记录真实教师测量或学校/教研组提供的记录；
- 没有数据时显示“尚未采集”，不画假图；
- 可录入教师匿名代号、课程、日期、传统/授渔备课时间、生成资源、人工修改比例、教师评价、专家结果；
- 支持 JSON/CSV 导出、匿名导出、JSON 导入、字段模板；
- 匿名导出会把教师代号替换为“教师01…”并清空备注/审核人，不修改原始记录。

### 知识图谱（`#/graph`）

- 课程 → 章节 → 知识点 → 典型任务；
- 点击节点查看说明、来源、审核状态；
- 只画有数据的边，没有知识包的课程不伪造关系。

### 竞赛演示（`#/demo`）

- 固定案例：机电一体化技术 / PLC技术及应用 / 物料分拣站 I/O 分配与接线检查；
- 点击“运行演示案例”自动生成资源包和质检；
- 不需要 AI Key，可离线运行；
- 页面明确标注演示数据边界，不声称真实课堂试用。

## 7. 资料中心

支持 TXT / MD / CSV / JSON / DOCX / PDF / XLSX / PPTX：

1. 拖入或选择文件（可多选）；
2. 本机解析，显示进度；
3. 如有疑似个人信息，先人工确认；可自动脱敏保存；
4. 预览提取内容（长文只显示前几块，完整内容在 IndexedDB）；
5. 选择“加入知识库”或仅保存资料；
6. 扫描 PDF 可启用 OCR（联网加载 Tesseract，需同意）。

单文件大小上限在设置页配置，默认 25MB。

## 8. 历史与备份

- 自动保存；可搜索、分类、收藏、改名、单条 / 批量删除；
- 优先存 IndexedDB；
- 设置页可导出完整备份 / 仅对话、导入恢复、删除本机数据；
- **不是云同步**。换设备请用备份文件迁移。

## 9. 隐私

- 输入含身份证、手机、邮箱、学号、姓名上下文、地址等时提示删除；
- 文件上传前检查，默认保存脱敏文本；
- AI 发送前检查：掩码展示，可自动脱敏发送或取消；
- AI 输出、安全条款、评价权重必须人工审核；
- 平台无法保证规则查全，请同时人工检查。

## 10. 常见问题

**没有网络 / AI 失败怎么办？**  
用本地模式；或点击结果上的“重试 AI 增强”。

**为什么 AI 只改写了几节？**

匿名体验通道有长度上限；本地结构保留完整，AI 专注改写关键模块。自建代理可使用更长输出。

**导出 PDF 为什么打开打印面板？**

PDF 由浏览器打印引擎生成，中文与分页最稳定；选择“另存为 PDF”。DOCX 有封面、文档目录、页码、表格防跨页和教师审核签字区；打印 PDF 有封面和目录。

**质检分为什么不是 100？**

知识包待教研组审核时按规则封顶 84；行业通用参考封顶 72。专业判断、设备参数和安全条款必须人工核对。分数不是学校官方认定。

**为什么只有四门课有完整知识包？**

要保证每条知识点都有来源、可追溯，不能批量编造。当前用 4 门不同方向课程证明方法和闭环，其余课程明确标为行业参考；4 门包仍是“待教研组审核”，不是学院正式课程标准。

**数据会上传吗？**

本地模式不上传；AI 模式会把必要上下文发给所选模型服务；文件解析默认只在本机，OCR 会加载外部 CDN。

**能跨设备同步吗？**

当前不能。没有账号与云端同步，不把本地存储宣传成同步。

**专业数据库里为什么很多课程显示“待完善”？**

原表只有 13 条课程简介是官方原文，其余 554 条没有公开课程简介。页面不按课程名编造官方内容；它提供明确标注的行业通用备课参考，教师可校订并保存。学院完整人才培养方案、课程标准、学时学分和教材版本未公开，需向课程负责人或教务处索取。

**专业库数据会不会改坏 Excel？**

不会。原始表作为只读种子保存；教师的新增、编辑、隐藏和课程资料写入浏览器 IndexedDB，并可单独导出修订。删除原始记录是“本机隐藏”，不是改写源文件。
