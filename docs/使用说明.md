# 匠备 · 使用说明

> 固定地址：[https://htfyu.github.io/jiangbei-teacher/](https://htfyu.github.io/jiangbei-teacher/)

## 1. 第一次打开

1. 首页先看「我能 / 我不做」两行边界；
2. 从 5 个场景入口选择一个，或在底部输入框直接描述任务；
3. 表单中带「必填」的字段会先校验；缺少学情、课型、学时或任务时，不会直接生成空泛模板；
4. 阅读结果时，同时查看右侧「引用来源」与「合规自检」；
5. 导出 Word 或用打印面板另存 PDF，**由教师人工审核后**再用于正式教学。

## 2. 五个场景

| 场景 | 适合什么时候用 | 关键输入 | 产出 |
|---|---|---|---|
| 生成教案 | 备新课、公开课、教学检查 | 专业、课程、任务、课型、学时、学情、设备 | 9 个模块的完整教学设计 |
| 任务单 / 工作页 | 要把教案转成学生材料 | 同上 + 输出类型 | 学习任务单 + 六步工作页 |
| 生成评价表 | 需要过程性评价、课堂观察或成果评价 | 专业、课程、任务、评价类型、学情 | 维度权重、三级评分细则、记录表 |
| 查安全规程 | 实训前查准入、用电、调试、应急 | 场所、具体操作、人员、关注点 | 分阶段核查清单 + 原文依据 |
| 听课评课 | 听完课要整理意见、教研留档 | 脱敏后的听课记录、观察重点 | 证据提取、亮点、缺口、改进建议 |

“载入示例”只用于演示，会自动填入一个完整的电气类任务。**正式使用前请按真实专业、任务与设备修改。**

## 3. 多轮修改

生成结果后，有两种修改方式：

- **直接说**：“把学时改成 6”“课型换成实训”“模板换成任务驱动简案”“补充：强调断电验电”；
- **点按钮**：结果上方「调整参数」或右侧任务条件「调整」。

系统会保留本次对话的条件，修改后重新生成一份，旧结果仍留在历史记录中。

## 4. 引用与“不知道”

- 每条知识库依据都细到章节，例如 `KB-05 §04`；
- 点击来源标签 / 右侧来源卡片，可打开原文并定位到对应章节；
- 安全知识库目前**只覆盖电工、PLC 实训室**；
- 询问数控、汽车、工业机器人等场所的安全规程时，助手会明确说“知识库没有收录”，不会套用电工规程；
- 听课记录中未出现的课堂事实，会标注“待确认”，不会补写或给无依据的分数。

## 5. 复制与导出

- 每个文档模块右上角有「复制」；
- 结果工具栏支持：复制全文、导出 Word、打印 / 另存 PDF、下载 Markdown；
- Word 文件为 `.doc`（HTML 格式），Word / WPS 可直接打开修改；
- PDF 使用浏览器打印面板生成，建议选择 A4、纵向、默认边距。

导出前请再检查一遍：是否含姓名、学号、联系方式、企业未公开信息。

## 6. 数据与隐私

- 本工具默认**不联网生成**，没有服务器；
- 输入、结果和历史只保存在当前浏览器的 `localStorage`；
- 换浏览器、换设备不会同步；清缓存会删除记录；
- 上传参考资料只支持本机 `.txt / .md / .csv / .json` 读取，不上传；
- 出现疑似手机号、身份证号、邮箱或“姓名：”时，会阻止继续处理；
- 不要在公共电脑保留含校内信息的记录。

## 7. 历史与反馈

- 左侧「历史对话」找回生成记录；
- 支持置顶与删除；删除后不可恢复；
- 结果底部「有用 / 需改进」只做本机统计，用于后续改进；
- 如要写试用材料，请邀请 1—2 位同事真实使用，使用站内「使用说明 → 试用反馈模板」记录，不要编造数据。

## 8. 常见问题

**Q：为什么不能直接双击 `index.html`？**  
A：页面使用 ES Module，本地文件协议会拦截模块加载。请用任意静态服务器打开，或直接访问线上地址。

**Q：为什么不接大模型也能生成？**  
A：公开版采用可审查的本地知识检索 + 结构化工作流，优点是无需密钥、打开即用、数据不出浏览器，缺点是开放式长文能力有限。它把“能不能用、有没有依据、边界是否清楚”放在“文采”之前。

**Q：知识库能换成学校自己的吗？**  
A：可以。修改 `js/knowledge.js` 中的 `KB_DOCS`，保持字段结构；页面统计、检索、引用与下载会自动更新。正式使用前由课程负责人审核并标注版本。

**Q：安全条款可以直接用于实训吗？**  
A：不能。所有安全内容均为教学提醒，必须对照实训中心现行制度、设备说明书和现场教师交底，由具备资质的人确认。

**Q：结果里出现不适合我们学校的内容怎么办？**  
A：这是 AI 辅助草稿的正常风险。请在导出前删除或替换，并把正确版本反馈给知识库维护人。不要直接使用未经审核的目标、权重或安全条款。
