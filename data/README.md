# data/ 数据说明

- `gzgj-professional-system.xlsx`：用户上传的《广州市技师学院专业体系数据库.xlsx》只读副本，92KB。站点“专业数据库”页提供下载。
- `programs-summary.json`：导入计数、专业系/组统计、课程类别分布和官方简介抽样；用于核验，不是运行时主数据。

运行时主数据由 `tools/generate_programs_data.py` 生成到 `js/programs-data.js`：

- 6 个教学单位
- 13 个专业组 / 学科组
- 56 个专业条目
- 75 条招生计划
- 567 条课程记录（484 个去重课程名称）
- 134 条来源记录
- 22 条数据说明

不要手工编辑生成文件。教师新增、编辑、隐藏和课程资料写入浏览器 IndexedDB，不改写上述文件。

完整说明见 `docs/专业数据库导入说明.md`。原始表中“暂无公开资料”“推定”“未纳入现行专业群”等状态均原样保留；未用推测内容替代学校未公开信息。
